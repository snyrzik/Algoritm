# Ваши решения

По желанию можно пользоваться черновиком на сайте: он сохраняет solution.hpp, solution.cpp и notes.md в day-XX/ID/. Те же файлы можно редактировать в своей IDE.

У каждого программного задания есть готовый main, пограничные случаи и ожидаемый вывод. Сравните результат в своей среде C++ и отметьте на сайте, всё ли совпало. Сайт не настраивает и не запускает компилятор.

Архивы проверки StereoLab B/C включают ваши файлы компонентов. Личные решения и прогресс не включаются в Git.
