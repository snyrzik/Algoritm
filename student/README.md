# Ваши решения

Реализации пишутся в своей IDE. Необязательный черновик на сайте сохраняет те же файлы в day-XX/ID/. Первая лекция использует Matrix2x2.hpp, Point2D.hpp, CMyString.hpp, DynamicVector.hpp и соответствующие .cpp; другие задания — solution.hpp/solution.cpp. notes.md предназначен для объяснений.

Скачайте готовый main, запустите в своей среде C++ и сравните результат. Отметьте на сайте, совпал ли он. Сайт не запускает компилятор; «Отмечено мной» — ваша ручная отметка о базовой проверке.

Авторские main проектов используют assert. Не отключайте его через NDEBUG. Память и дополнительные граничные случаи проверьте самостоятельно. Личные решения и прогресс исключены из Git.
