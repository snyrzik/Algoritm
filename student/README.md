# Ваши решения

После `npm start` или `npm run prepare:course` здесь находятся пять папок `day-01`…`day-05`, внутри — отдельная папка для каждого задания.

`solution.hpp` и `solution.cpp` — ваш C++, `notes.md` — объяснения. Файлы не заменяются при повторной подготовке курса. Они игнорируются Git, поэтому для резервной копии сохраните папку целиком вместе с `../progress/`.

Для задач B/C можно переносить свой код из ранее выполненных задач. Каждый комплект проверяется независимо; автоматического подключения соседних незавершённых решений нет.
