## Проверка и баллы

Программные задания сдаются по самостоятельной отметке. В каждом задании доступны main для проверки, перечень обычных и пограничных случаев, ожидаемый вывод и кнопки «Да, всё совпало» / «Есть расхождения». После положительной отметки начисляется вес задания из таблицы; после отрицательной — 0. История сохраняет обе попытки.

Вопросы Q и предсказания P проверяются на сайте. Объяснение P сохраняется для разбора; оценка причин опирается на причинную трассировку. Для программных S/D/A/B/C сайт не запускает C++ и не требует установленного компилятора. Отметки обозначаются «Проверено мной».

C1 сопровождается готовым main для функции `run_stereolab(std::istream&,std::ostream&)`, входными сценариями, числовым выводом и примерами поведения при ошибках. Допуск чисел — 1e-9. Для всех остальных программных заданий ожидаются строки `case-NN: OK` и итоговое `ALL CHECKS PASSED`.

## Файлы проверки

Main можно скопировать, скачать отдельно или получить ZIP вместе с текущими исходниками. В архив A2/A3 включены минимальные вспомогательные заголовки для автономной проверки. В B/C включаются именно ваши компоненты A1–A3 и B1–B2.

Существующие файлы на диске не перезаписываются при скачивании. В архиве `main.cpp` содержит проверочный пример; добавьте его и файлы реализации в свой C++17-проект.

Ключи Q/P открываются после ответа. Программные проверки теперь открыто показаны в main по запросу пользователя. Полные контрольные реализации остаются только в тестовой инфраструктуре и не подставляются в ученические решения.

Подробности: [самостоятельная сдача](self-check.md).

## Чистая версия

В проекте оставлена только текущая практика StereoLab. Ученические ответы, черновики, попытки и прогресс не входят в Git. При первом запуске создаются начальные файлы без решений; исходные дефектные фрагменты D остаются условиями упражнений.

Новый пустой профиль получает отдельный идентификатор. Браузер удаляет черновики предыдущего профиля, чтобы они не восстановили старые ответы. Теория и Дни 2–5 сохраняют свои учебные материалы.
