# Python Recall: отдельный предмет

Открыть [Python Recall](http://127.0.0.1:8765/#/python) или выбрать предмет в списке под логотипом. C++ остаётся доступен по прежним ссылкам. Его курс, прогресс, закладки и исходники не смешиваются с Python.

Восемь недель содержат по пять задач — всего 40. Это повторение ранее изученного синтаксиса по 15–25 минут, без календарных блокировок. Условия, правила, примеры, границы, скрываемые подсказки, усложнения и стартеры импортированы из исходного пакета. Для дня 14 поддержаны оба файла: `main.py` и `utils.py`. Редактор и примеры подсвечивают Python.

Файлы ученика сохраняются в `student/python/py-XX/`. Существующий механизм черновиков и конфликтов с IDE работает для обоих предметов. «Скачать мои файлы» выдаёт ZIP собственных исходников, полного условия и инструкции локального запуска.

На сайте нет выполнения Python. Для функций нужны собственные вызовы или assert по примерам; CLI и GUI запускаются в локальной среде. Зависимости показываются только у соответствующих задач. Дополнительные лабораторные темы можно пропустить, отметить как уже изученные или заменить повторением старых задач. Общий процент основного повторения считается по 26 основным задачам; 14 дополнительных учитываются отдельно.

## Самостоятельная попытка и эталоны

Просмотр задачи, подсказки и сохранение неизменённой заготовки не открывают эталон. После изменения кода нужно нажать «Сохранить попытку». Комментарии и пробелы сами по себе не считаются изменением решения. Если работа выполнена в собственной IDE, отметьте это и добавьте объяснение от 20 символов.

Проверка доступа выполняется сервером для каждой задачи. Только после сохранённой попытки кнопка «Показать эталон» получает право загрузить один соответствующий вариант и объяснение. Ответ не включён в каталог, исходники интерфейса, публичную статику, черновик или собственный ZIP. Его просмотр не завершает задачу. Для ручного завершения нужна своя попытка и отметка о локальной проверке.

Прогресс хранится в отдельных таблицах той же SQLite-базы: `python_state`, `python_attempts`, `python_learning`. Сохраняются статусы, снимки попыток, заметки, закладки, субъективная сложность, слабые темы, пропуски и позиция в курсе. Есть отдельные страницы повторения и экспорта прогресса Python.

## Исходные материалы и перенос установки

Публичные материалы находятся в `content/python-recall/`. Исходные SHA-256 всех файлов пакета — в `source.sha256.json`. Приватные эталоны, объяснения и авторские тесты размещаются в `.private/python-recall/`; эта папка исключена из Git и браузерного бандла.

На текущем компьютере эталоны уже импортированы. После нового клонирования репозитория импортируйте их из собственного исходного архива:

```powershell
npm install
npm run import:python -- "C:\Users\games\Downloads\python_recall_8_weeks.zip"
npm start
```

Импорт сохраняет исходные байты материалов и не изменяет ученические файлы или прогресс. Без приватного импорта публичный курс работает, но эталоны недоступны.

Архитектура: `subjects/SubjectRouter` выбирает предмет по маршруту, общий `SubjectSwitcher` связывает разделы; `PythonApp` использует существующее оформление и механизм сохранения. Серверная часть Python выделена в `backend/python_recall.py`, а старые API C++ сохранены.

Проверки разработки: `npm run build`, `npm test`, `npm run test:python-browser`. Браузерный сценарий использует временный профиль, открывает все 40 задач, проверяет блокировку эталонов, самостоятельные попытки, два файла дня 14, конфликт с IDE, ZIP, пропуски, закладки, переключение предметов, перезапуск, обе темы и мобильную ширину. Отдельно сверяется неизменность исходных материалов C++ и существующей истории.
