# Лекции № 2 и № 3

Готовый пакет находится в `content/lectures-02-03/`. Все 14 исходных файлов сохранены побайтно; `source.sha256.json` фиксирует исходные контрольные суммы. Теория целиком разбивается на обзор, четыре главы и заключение, без сокращения примеров или объяснений.

Открыть: `http://127.0.0.1:8765/#/theory/2/overview` и `#/theory/3/overview`. В каждом модуле есть теория, практика, локальная проверка и самостоятельные результаты. Лекция 2 явно отмечена как восстановленный переходный модуль, без приписывания отсутствующего PDF преподавателю.

Лекция 2 содержит четыре закрепления и два проекта: расширения CMyString и DynamicVector. В первой лекции использовались `.hpp`, в новом пакете main включает `.h`: предоставлен только include-переходник. Если существующие файлы пользователя сохранены на сайте, они копируются в новый черновик один раз; старые исходники не перезаписываются. Класс продолжает разрабатывать ученик.

Лекция 3 содержит четыре закрепления и три проекта: шаблонные функции, FixedStack и IStack/LinkedStack. RTTI — закрепление четвёртой главы. Постфиксный вычислитель — второй, независимо проверяемый этап третьего проекта. Его незавершённость не блокирует сохранение результата проверки стека; общий проект завершается после обеих отметок.

Семь исходных `MAIN_*.cpp` доступны для просмотра, копирования и скачивания. Каждый main компилируется отдельно, без `NDEBUG`. Команды GCC/Clang, Windows PowerShell и пояснения Visual Studio доступны во вкладке локальной проверки. Санитайзеры используются только локально при поддержке среды, и их запуск не считается исчерпывающей проверкой.

Код и объяснения самостоятельных закреплений пишет ученик. Для закреплений, к которым автор не приложил main, сайт не генерирует имитацию теста. Положительная отметка требует подтверждения критериев и письменного объяснения; память, неуспешные сценарии и подсказки сохраняются раздельно.

Прежние условия и проверки практикума всех модулей 2–5 удалены. Их личные исходники, заметки, история и SQLite-снимки сохранены. Раздел прогресса позволяет скачать ранее сохранённые файлы и результаты; старые задания не возвращаются в учебную навигацию. В программе остались только лекции 1–3. Лекция 1 не менялась.

Проверка: `npm run build`, `npm test`, `npm run test:lectures-browser`. Необязательная `npm run test:lecture-mains` проверяет синтаксис семи авторских main по объявлениям API во временном каталоге; реализации классов и пользовательский C++ не запускаются.
