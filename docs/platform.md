# Учебная платформа

Главная страница — «Моё обучение». Новый пользователь начинает с первой главы, следующий вход предлагает последний учебный материал или следующий невыполненный шаг. Программа состоит из пяти открытых модулей без сроков. В модуле 1 есть полная авторская лекция; модули 2–5 явно обозначены как практикумы.

Маршруты: `#/home`, `#/program`, `#/module/1` … `module/5`, `#/search`, `#/saved`, `#/review`, `#/report`, `#/settings`, `#/help`. Старые `#/day/N` и все ссылки на лекцию и задания продолжают работать. Неизвестный адрес показывает страницу с возвратом к программе.

API курса включает все 248 заданий. Процент относится к 247 обязательным заданиям; дополнительное не влияет на него. Прочтение глав, проверенные ответы и самостоятельные отметки разделены. Прогресс не объявляет оценку владения темой на основе процента или числа попыток.

Поиск охватывает название, темы и текст каждого задания. Фильтры по типу, модулю и состоянию применяются ко всему набору, затем выдача разбивается на порции по 20 с работающим «Показать ещё». Закладки и возобновление хранятся в таблице learner_state, независимо от результатов. `GET/POST /api/learning` проверяет существование заданий и допустимость маршрута.

Чтение, закладки и переходы не создают попытки и не завершают задания. Перезапуск сохраняет маршрут и подборку. Тема и размер текста сохраняются в браузере. Исходные тексты, задания и проверочные main не переписаны.

Необязательные черновики автоматически сохраняются и доступны в IDE. В разделе «Файлы и сохранение» можно сохранить файл, скачать черновик или загрузить версию с диска. При конфликте перед загрузкой скачивается несохранённый черновик. Если код изменился после отметки о проверке, интерфейс предлагает повторить проверку.

Короткие SQLite-транзакции сериализованы между HTTP-потоками: параллельная загрузка данных не вызывает блокировку при повышении читающей транзакции до записывающей. Определения курса кешируются на время процесса; пользовательские файлы читаются с диска. После изменения учебных определений сервер нужно перезапустить.

Проверки: `npm run build`, `npm test`, `npm run test:browser`, `npm run test:platform-browser`. Последний сценарий проходит главную, программу, все задания в поиске, фильтры, закладки, продолжение, отчёт, ошибки, восстановление конфликта, настройки, мобильные страницы, неверные адреса и перезапуск. Каждый браузерный тест использует отдельный временный профиль.
