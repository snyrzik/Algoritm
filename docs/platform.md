# Учебная платформа

Главная страница — «Моё обучение». Программа содержит четыре открытые лекции с теорией, закреплениями, проектами и локальной проверкой. Сроков прохождения нет. Главная предлагает последний материал или следующий невыполненный шаг.

Маршруты: `#/home`, `#/program`, `#/module/1` … `#/module/4`, `#/theory/N/chapter-K`, `#/search`, `#/saved`, `#/review`, `#/report`, `#/settings`, `#/help`. Неизвестный адрес показывает возврат к программе. Старые задания интенсива недоступны; новый модуль 4 посвящён спискам и STL.

Каталог содержит 28 обязательных заданий: 17 закреплений и 11 проектов. Чтение 17 глав учитывается отдельно. Процент выполнения строится только по действующей программе; прежние результаты не завершают новые задания. Самопроверка означает ручную отметку ученика.

Поиск охватывает название, темы и текст заданий. Фильтры по закреплениям, проектам, модулю и состоянию применяются ко всему набору, затем выдача разбивается на порции по 20. Закладки и возобновление хранятся независимо от результатов. Чтение, переходы и скачивание main не создают попытки.

Вся компиляция C++ выполняется учеником локально. Сайт предоставляет проверочные main, ожидаемый вывод и критерии. В закреплениях без приложенного автором main нужно самостоятельно написать код и объяснение. В новых лекциях отдельно сохраняются ошибки, подсказки и состояние проверки памяти. Два этапа проекта LinkedStack проверяются независимо.

Личные файлы сохраняются в `student/`, история — в `progress/mastery.sqlite3`. Все 240 старых заданий прежнего интенсива удалены вместе с условиями и проверками. Существующие личные исходники и результаты сохраняются; в прогрессе можно скачать их отдельным архивом. Старые задания не возвращаются в навигацию.

Черновики автоматически сохраняются и доступны в IDE. При конфликте версий интерфейс позволяет скачать несохранённый текст и загрузить файл с диска. Если код изменился после отметки, предлагается повторить проверку. Новый проект копирует собственную базовую реализацию ученика только при первом создании черновика; существующие файлы не перезаписываются.

Определения курса кешируются на время процесса. После изменения учебных файлов сервер нужно перезапустить. SQLite-транзакции сериализованы между HTTP-потоками. Тема и размер текста сохраняются в браузере.

Проверки перечислены в [verification.md](verification.md). Все браузерные сценарии используют отдельные временные профили.
