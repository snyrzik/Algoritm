# Самостоятельная сдача

Программные задания используют готовый `main`, список случаев и ожидаемый вывод. На сайте доступны раскрытие кода, скачивание `main.cpp`, архив исходников и две отметки: «Да, всё совпало» и «Есть расхождения».

Открытие main или скачивание архива не завершает задание. Только явная отметка пользователя создаёт попытку `mode=self-check`: `SELF_CHECKED` либо `NEEDS_WORK`. Изменение результата сохраняет новую запись в истории. Прогресс, карточки этапов и четыре закрепления теории учитывают эти отметки.

Вопросы Q и предсказания P сохраняют прежнюю проверку ответов. Программная самопроверка не выдаётся за независимый автоматический зачёт. Для неё не требуется предварительный диагностический разбор D или запуск программы на сервере.

## Готовые main

`backend/self_check.py` готовит примеры для 171 задания и 551 обычного, граничного или ошибочного случая. Примеры содержат проверочные вызовы, проверку исключений и типов; при совпадении печатаются строки `case-NN: OK` и `ALL CHECKS PASSED`. Несовпадение сообщает номер случая и причину. В упражнениях на память необходимые вспомогательные средства уже входят в проверочный файл.

В C1 показаны отдельные входные сценарии, числовой вывод и ожидаемое поведение при ошибке. Числовые представления могут отличаться числом знаков; сравнение делается с допуском из условия. Текст диагностики ошибок формата может отличаться, если сообщение понятно, stdout остаётся пустым и программа завершается с ошибкой.

Проверочный архив содержит фактические пользовательские исходники. Для B/C добавляются их зависимости; исходники компонентов имеют разные имена, чтобы объектные файлы не конфликтовали в IDE. `main.cpp` в архиве — пример для проверки; существующий `main.cpp` пользователя на диске не перезаписывается.

## Сервер

- `GET /api/self-check/ID` — main, ожидаемый вывод и случаи.
- `GET /api/self-check-bundle/ID` — ZIP с файлами проверки.
- `POST /api/self-check/ID` — явная отметка `{completed, checkedCases}`.
- Старые `/api/doctor` и `/api/run/ID` возвращают 410. Они не вызывают компилятор.

Сервер не импортирует подсистему компиляции при старте и не ищет установленные компиляторы. Нативные средства проверки оставлены только для необязательной проверки разработки.
