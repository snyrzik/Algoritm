# Самостоятельная проверка

Решение пишется и запускается в собственной IDE. Сайт предоставляет условие, граничные случаи, проверочный main и ожидаемый вывод, если main есть в авторском пакете. Для остальных закреплений предусмотрены критерии и письменное объяснение без имитации автоматического теста. Сайт не ищет компилятор и не выполняет C++.

Три проекта первой лекции используют исходные авторские main с assert. Не задавайте NDEBUG. Проверочные main проверяют базовые сценарии; дополнительные граничные случаи и безопасность памяти проверяются отдельно.

Кнопки «Да, всё совпало» и «Есть расхождения» сохраняют ручную отметку `SELF_CHECKED` или `NEEDS_WORK`. Просмотр, копирование и скачивание не засчитывают работу. Отметку можно изменить; история сохраняется. В лекциях 2–4 положительная отметка требует подтверждения критериев, а закрепления — также собственного объяснения. Ошибки памяти препятствуют положительной отметке.

В лекции 3 LinkedStack и PostfixEvaluator — два отдельных этапа одного проекта. Результат стека можно сохранить до завершения вычислителя; проект завершён после обоих этапов. Состояние памяти, ошибки и подсказки записываются отдельно.

Для лекции 1 действуют `GET/POST /api/self-check/ID`, `GET /api/self-check-bundle/ID` и отдельный `POST /api/lecture-read/chapter-N`. Для лекций 2–4 — `GET /api/lecture-task/ID`, `POST /api/lecture-state/ID`, `GET /api/lecture-bundle/ID`, `GET /api/lecture-main/N/FILENAME` и `POST /api/lecture-reading/N`. Чтение не завершает задания. Старые API компиляции и таймеров возвращают 410 и ничего не выполняют.
