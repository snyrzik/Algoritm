# Проверка текущей версии

Действующий каталог: 288 заданий, включая 48 StereoLab, и четыре отдельных закрепления теории Дня 1. Пользовательские решения, SQLite, резервные копии и кэш сборок не включаются в Git.

## Команды

```text
npm run prepare:course
npm run build
npm test
npm run test:contracts
npm run test:browser
npm run test:theory-browser
npm run test:day01-browser
```

Автотесты работают во временном профиле. Они проверяют каталог, закрытые ключи, реальную компиляцию C++17, контрольные реализации и намеренные ошибки, зависимости B/C, оценки, потоковые ошибки и исключения. Проверяются также конфликты сохранения, локальная сессия, история попыток, тайм-ауты, ограничения вывода и доступные средства контроля памяти.

Контракты практики компилируются против отдельных деклараций API. Контрольные реализации StereoLab находятся только в тестовой инфраструктуре и никогда не подставляются в пользовательские файлы.

Текст лекции проверяется по байтовой контрольной сумме исходного Markdown. Контрольные суммы действующих материалов других дней находятся в `tests/course_content.sha256.json`.

Браузерные проверки охватывают навигацию, обе темы, мобильные редакторы, автосохранение, причинную трассировку и доступ к редактору D после диагностики. Проверка чистого профиля убеждается, что черновики предыдущего профиля удаляются, а черновики текущего переживают перезагрузку.

## Чистый учебный профиль

Остановите локальный сервер перед сбросом. Первая команда показывает объём очистки без удаления:

```text
python tools/reset_workspace.py --clear-cache
python tools/reset_workspace.py --apply --clear-cache
npm run prepare:course
```

Сброс проверяет все пути и имена файлов до удаления. Он очищает ученические ответы, историю и резервные копии прогресса; с `--clear-cache` очищаются также локальные сборки и результаты проверок. Неизвестный файл в ученических данных останавливает операцию. Учебные материалы, исходники приложения, Git, `student/README.md` и `progress/.gitkeep` сохраняются.

Первый запрос создаёт идентификатор нового профиля. Браузер удаляет черновики предыдущего профиля перед загрузкой заданий.

## Границы проверки

На текущем Windows проверяется MSVC C++17 со строгими предупреждениями и AddressSanitizer; доступность каждого инструмента определяется фактическим запуском. Свободные объяснения P/D сохраняются для содержательного разбора. Автоматические баллы опираются на причинную трассировку, выбранные правила и проверяемое поведение. Стиль, читаемость и качество проектирования требуют отдельного review.
