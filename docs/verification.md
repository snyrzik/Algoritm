# Проверка текущей версии

Каталог: 243 основных задания (три новых проекта Дня 1 и 240 заданий других дней), пять отдельных закреплений. Старые задания первой лекции и их данные удалены; новые ID не наследуют их прогресс.

```text
npm run build
npm test
npm run test:browser
```

Тесты используют временный учебный профиль. Проверяются авторская теория и три main по байтовым SHA-256, отсутствие старых заданий, изоляция очистки Дня 1, сохранность 626 материалов остальных дней, ручные отметки, отдельное прочтение, файловые конфликты, сессии и экзамен.

Браузерная проверка открывает все пять глав, пять закреплений, три проекта, остальные дни; проверяет C++-подсветку, схемы, копирование, скачивание main, историю, черновики и перезапуск. Проверяются темы и мобильная ширина. Запросы компилятора отсутствуют.

Необязательный `npm run test:manual-mains` проверяет синтаксис/API 37 main по объявлениям классов во временном каталоге, при наличии локального C++17-компилятора. Это проверка разработки, не проверка правильности ученических решений и не часть работающего сайта.

Для полной очистки учебного профиля остановите сервер:

```text
python tools/reset_workspace.py --clear-cache
python tools/reset_workspace.py --apply --clear-cache
```

Первая команда показывает объём очистки. Пути и имена файлов проверяются до удаления; неизвестный файл останавливает операцию. Учебный код, Git, student/README.md и progress/.gitkeep сохраняются. При новом профиле браузер удаляет старые черновики.
