# Проверка текущей версии

Действующий каталог: 288 заданий, включая 48 StereoLab, и четыре отдельных закрепления теории Дня 1. Пользовательские решения, SQLite, резервные копии и кэш сборок не включаются в Git.

## Команды

```text
npm run prepare:course
npm run build
npm test
npm run test:contracts
npm run test:browser
npm run test:theory-browser
npm run test:day01-browser
```

Автотесты работают во временном профиле. Они проверяют каталог, закрытые ключи, выдачу готовых main и ожидаемого вывода, архивы B/C, явное подтверждение и изменение результатов самопроверки. Проверяются также конфликты сохранения, локальная сессия, история попыток, тайм-ауты, ограничения вывода и доступные средства контроля памяти.

Обычный `npm test` не требует C++-компилятора. Для разработчика отдельно доступен `npm run test:manual-mains`: контрольные реализации проверяют ожидаемый вывод готовых mains, а заведомая ошибка должна дать FAIL. Проверка выполняется во временном профиле и не вызывается сайтом.

Текст лекции проверяется по байтовой контрольной сумме исходного Markdown. Контрольные суммы действующих материалов других дней находятся в `tests/course_content.sha256.json`.

Браузерные проверки охватывают навигацию, обе темы, мобильные редакторы, автосохранение, причинную трассировку и самостоятельную сдачу D и сохранение отметок после перезагрузки. Проверка чистого профиля убеждается, что черновики предыдущего профиля удаляются, а черновики текущего переживают перезагрузку.

## Чистый учебный профиль

Остановите локальный сервер перед сбросом. Первая команда показывает объём очистки без удаления:

```text
python tools/reset_workspace.py --clear-cache
python tools/reset_workspace.py --apply --clear-cache
npm run prepare:course
```

Сброс проверяет все пути и имена файлов до удаления. Он очищает ученические ответы, историю и резервные копии прогресса; с `--clear-cache` очищаются также локальные сборки и результаты проверок. Неизвестный файл в ученических данных останавливает операцию. Учебные материалы, исходники приложения, Git, `student/README.md` и `progress/.gitkeep` сохраняются.

Первый запрос создаёт идентификатор нового профиля. Браузер удаляет черновики предыдущего профиля перед загрузкой заданий.

## Границы проверки

Встроенный компилятор отключён; сервер не ищет и не запускает его. Свободные объяснения P/D сохраняются для содержательного разбора. Баллы Q/P опираются на ответ и причинную трассировку; баллы программных задач — на отметку пользователя. Стиль, читаемость и качество проектирования требуют отдельного review.
