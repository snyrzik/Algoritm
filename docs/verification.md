- Локальную сессию, запрет чужого Origin и запрет изменения без токена.

`npm run test:contracts` компилирует все **37 практических тестовых программ** против деклараций API. Эти тестовые фикстуры не содержат решений: они не линкуются в учебный раннер, отдельные шаблоны только бросают исключение. Проверка находит ошибки в сигнатурах и самих тестовых программах; она **не заменяет** прогон полноценного решения каждого упражнения.

`npm run test:browser` проверяет пять дней, светлую/тёмную темы, теоретическую попытку, реальные ошибки C++ и успешный C++-запуск в отдельном временном профиле, сохранение фокуса при наборе, автосохранение, несколько файлов, перезагрузку страницы, историю, повторение, отчёт, перезапуск сервера и размеры 1440×1080, 1366×768, 390×844.

Учебные стартеры не являются эталонными решениями и не должны проходить функциональные тесты. Проверки инфраструктуры отделены от учебных результатов.

## Память и исключения

Каждый C++-сценарий выполняется отдельным процессом. Все тесты связываются с инструментированными обычными new/new[]/delete/delete[]. Счётчик сравнивается до/после сценария, несоответствие семейств вызывает ошибку. В памяти используется дополнительный заголовок с естественным максимальным выравниванием. Инструмент не является универсальным анализатором собственного malloc/пулов/over-aligned new.

В упражнениях CMyString и replace_range проверяется реальный отказ выделения; Tracked проверяет живые объекты и броски при копировании/присваивании. TSequence проверяется на откат push_back/insert/erase/присваивания/конструирования копии, а также на алиасинг при росте.

Доступные на этом Windows средства: MSVC C++17, AddressSanitizer. Недоступные в этой конфигурации: UBSan и LeakSanitizer. Интерфейс и результаты отражают это раздельно. Полная доказательная проверка отсутствия всех UB/утечек не заявляется.

## Ручная часть оценки

Автоматическая система проверяет наблюдаемое поведение, типы и перечисленные статические ограничения. Разбор в notes.md, качество проектирования, читаемость, объяснение рисков преобразований и ограничения непроверяемых предельных размеров требуют самостоятельного review. Достаточная длина notes.md лишь фиксирует наличие разбора, а не подтверждает его правильность.

Устойчивость знания требует повторного самостоятельного применения; простое повторное нажатие кнопки на том же решении не даёт статус освоенной темы. Локальный курс не является защищённой экзаменационной системой: пользователь имеет доступ к исходникам тестов и может осознанно изучить их. Интерфейс не раскрывает ответы заранее.
