# Проверка текущей версии

В программе четыре лекции, 17 глав, 17 закреплений и 11 проектов: всего 28 обязательных заданий. Все 240 старых заданий модулей 2–5 удалены. Лекция 1, личные файлы и история сохраняются.

```text
npm run build
npm test
npm run test:browser
npm run test:platform-browser
npm run test:lectures-browser
npm run test:lecture04-browser
```

48 Python-тестов проверяет неизменность авторских материалов, состав программы, отсутствие готовых решений, отдельное чтение, критерии ручных отметок, независимость этапов LinkedStack, наследование собственных исходников без перезаписи, конфликты, защиту сессий, скачивание ранее сохранённых решений и недоступность компилятора.

Браузерные сценарии проходят главы и задания лекций 1–4, проверяют отображение полного текста и кода, навигацию, копирование и скачивание main, поиск, фильтры, закладки, возобновление, прогресс, ошибки, черновики, восстановление конфликта, перезапуск, темы и мобильные страницы. Все сценарии работают с временными профилями.

Необязательные `npm run test:manual-mains` и `npm run test:lecture-mains` проверяют синтаксис/API 8 main первой лекции и 10 исходных main лекций 2–4 по объявлениям классов. Нужен локальный C++17-компилятор. Реализации ученических классов не создаются и не запускаются. Эти команды не вызываются сайтом.

При интеграции отдельно сверяются SHA-256 существующих ученических файлов и строки таблиц истории с исходным снимком. Обычный запуск и обновление программы не очищают профиль.
