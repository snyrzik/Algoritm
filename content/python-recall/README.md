# Python Recall — ежедневная практика, 8 недель / 40 дней

**Цель:** 15–25 минут повторения уже пройденного синтаксиса Python перед основной учёбой. Не второй курс и не лабораторные работы. Один день = одна небольшая самостоятельная задача. Выходные свободные; сложные задачи и новые темы остаются у основного преподавателя.

## Что внутри

- `tasks/week_01/day_01.md` ... `tasks/week_08/day_05.md`: **40 полных условий** с примером, точными правилами, граничными случаями, подсказкой и необязательным усложнением.
- `solutions/day_01.py` ... `solutions/day_40.py`: **40 эталонных вариантов решения**. День 14 — два файла `solutions/day_14/utils.py` и `main.py`.
- `explanations/day_01.md` ... `day_40.md`: короткие объяснения синтаксиса и подхода.
- `starters/`: заготовки с сигнатурами и `pass`, которые можно давать в редакторе сайта.
- `tests/test_solutions.py`: автоматические проверки эталонных решений (GUI-кейсы проверяются на компиляцию; UI проверяется вручную).
- `import/public_catalog.json`: данные для показа задач на сайте **без решений**.
- `import/private_solutions.json`: решения и объяснения для **серверной, приватной части** сайта. Не публиковать как static JSON!
- `AGENT_INTEGRATION.md`: инструкция для веб-программиста/агента.

## Учебный режим

1. Открой очередной день; напиши решение самостоятельно без просмотра `solutions/`.
2. Если застрял — разверни подсказку. Если быстро справился — сделай необязательное усложнение.
3. После попытки сравни решение с эталоном. Проверяй не только результат, но и синтаксис: циклы, словари, `try/except`, `with`, `class`, `yield` и т. д.
4. Отмечай слабые конструкции, чтобы вернуться к ним позднее.
5. С недели 5 используй специализированные задания только после того, как уже проходил соответствующую тему; иначе замени их повторением прошлых дней.

## Соответствие учебным материалам

**Лекции:** https://github.com/itsecd/application-programming-2025 — в README заявлены 1 (знакомство с Python), 2 (коллекции, функции, исключения), 3–4 (файлы, модули/пакеты), 5 (ООП), 7 (web scraping). Лекция 6 описывает направления разработки. В репозитории есть и более поздние каталоги, но этот набор не предполагает, что все их темы уже были изучены.

**Лабораторные:** https://github.com/itsecd/application-programming-labs — задания на `re`, Web Scraping и итераторы, NumPy, Pandas, GUI на **PyQt5**. В `lab_guide.md` сформулированы требования к PEP8, функциям/классам, type hints, docstrings, модулям и конструкции `if __name__ == "__main__"`.

**Важно:** условия и эталонные решения — **новые авторские учебные примеры, составленные по темам и требованиям курса, а не копии кода из тетрадей преподавателя**. Полные содержимое всех ноутбуков лекций не было проверено построчно; привязка к лекциям основана на доступном перечне тем и материалах лабораторных. Это честнее, чем приписывать оригинальные решения преподавателю.

## Проверка

Рекомендуемая версия Python: **3.10+** (используется синтаксис `|` для объединения типов). Для задач 1–25 и 29–30, 35, 38–40 достаточно стандартной библиотеки. Для задач 26–28 установи BeautifulSoup, для 31–32 NumPy, для 33–34 Pandas; для GUI 36–37 требуется PyQt5 и графическая среда.

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests
```

Для запуска GUI (если PyQt5 установлен):

```bash
python solutions/day_36.py
python solutions/day_37.py
```

Не путай **номера дней**: `day_01` в каждой папке `tasks/week_XX/` означает день недели, а `solutions/day_01.py` означает глобальный номер задачи. `id = py-01` ... `py-40` однозначен и подходит для базы данных.
