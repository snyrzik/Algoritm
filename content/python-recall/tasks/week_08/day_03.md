## Задание

Разбери события формата YYYY-MM-DD TYPE (дата и тип, разделённые пробелами); составь вложенный словарь дата -> тип -> количество.

## Интерфейс

```python
event_counts(lines: list[str]) -> dict[str, dict[str, int]]
```

## Точные правила

Дата проверяется только по шаблону 4 цифры-2 цифры-2 цифры, без календарной валидации. TYPE состоит из латинских букв в верхнем регистре. Неверные строки пропускай.

## Пример

```text
["2026-01-01 LOGIN", "2026-01-01 LOGIN", "2026-01-02 LOGOUT"] => {"2026-01-01":{"LOGIN":2}, "2026-01-02":{"LOGOUT":1}}
```

## Граничные случаи

Пустые строки, неверный регистр типа, лишние части.
