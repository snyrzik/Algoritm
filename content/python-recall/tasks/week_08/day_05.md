## Задание

Реши две независимые части: (1) верни список уникальных чисел в порядке первого появления; (2) подсчитай слова текста без учёта регистра.

## Интерфейс

```python
two_warmups(values: list[int], text: str) -> tuple[list[int], dict[str, int]]
```

## Точные правила

Слова — последовательности русских/латинских букв, как в задаче 6. Ответ — кортеж (список чисел, словарь частот).

## Пример

```text
([2,1,2,3], "Кот кот пес") => ([2,1,3], {"кот":2,"пес":1})
```
