## Задание

Напиши класс, который хранит расходы как пары (категория, сумма), добавляет записи, вычисляет сумму по всем категориям или выбранной категории и сохраняет/читает CSV.

## Интерфейс

```python
class ExpenseTracker: add(category, amount), total(category=None), save(path), load(path)
```

## Точные правила

Суммы — положительные целые, категория непустая после strip. CSV имеет заголовки category,amount; load заменяет существующие записи и пропускает испорченные строки.

## Пример

```text
add("food", 100), add("taxi", 50), total() => 150; total("food") => 100
```

## Граничные случаи

Пустой трекер, повреждённый CSV, пустые категории.
