## Задание

Вычисли средний балл каждого студента и верни рейтинг.

## Интерфейс

```python
student_rating(grades: dict[str, list[int]]) -> list[tuple[str, float]]
```

## Точные правила

Студентов без оценок пропусти. По убыванию среднего, при равенстве по имени по возрастанию. Средние не округляй.

## Пример

```text
{"Аня": [5, 4], "Борис": [3, 3], "Вера": []} => [("Аня", 4.5), ("Борис", 3.0)]
```

## Граничные случаи

Пустой словарь, одно значение, равные средние.

</details>
