## Задание

Два человека указали свободные часы суток целыми числами. Верни общие часы в порядке возрастания.

## Интерфейс

```python
common_hours(first: list[int], second: list[int]) -> list[int]
```

## Точные правила

Допустимы только часы от 0 до 23; дубликаты убрать. Некорректные часы исключить.

## Пример

```text
[9, 11, 11, 25, 15], [11, 15, 17] => [11, 15]
```

## Граничные случаи

Нет совпадений; все часы вне диапазона.
