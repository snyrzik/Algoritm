## Задание

Найди самые частые слова в тексте. Слова — последовательности русских или английских букв; числа разделяют слова. Игнорируй регистр.

## Интерфейс

```python
top_words(text: str, limit: int = 3) -> list[tuple[str, int]]
```

## Точные правила

Сортировка: частота по убыванию, при равенстве слово по алфавиту; limit <= 0 => [].

## Пример

```text
"Кот, кот! Дом. дом кот" => [("кот", 3), ("дом", 2)]
```

## Граничные случаи

Пустой текст, только знаки препинания, равная частота.

<details><summary>Подсказка (открывай только если застрял)</summary>

re.findall(r"[a-zа-яё]+", text.lower())

</details>
