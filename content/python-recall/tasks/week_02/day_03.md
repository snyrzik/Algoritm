## Задание

Реализуй калькулятор состояния: команда ADD N прибавляет N, REMOVE N вычитает N, SHOW добавляет текущее значение в список результатов.

## Интерфейс

```python
parse_numbers(commands: list[str]) -> list[int]
```

## Точные правила

Первоначальное значение 0. Для ADD и REMOVE требуется ровно один целый аргумент (включая отрицательный); ошибочные команды пропускай. SHOW без аргументов.

## Пример

```text
["ADD 5", "ADD abc", "REMOVE 2", "SHOW", "ADD -4", "SHOW"] => [3, -1]
```

## Граничные случаи

Неизвестная команда, пустая строка, SHOW до операций.

<details><summary>Подсказка (открывай только если застрял)</summary>

try: int(...); except ValueError

</details>

## Если осталось время (необязательно)

Добавь команду RESET без аргументов.
