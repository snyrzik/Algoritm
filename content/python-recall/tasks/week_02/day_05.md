## Задание

Объедини имена и баллы, отсортируй по убыванию балла и по имени при равенстве. Присвой порядковые места начиная с 1.

## Интерфейс

```python
score_table(names: list[str], scores: list[int]) -> list[tuple[int, str, int]]
```

## Точные правила

Если длины списков отличаются, учитывай только полные пары (поведение zip).

## Пример

```text
["Аня", "Борис", "Вера"], [80, 90, 90] => [(1, "Борис", 90), (2, "Вера", 90), (3, "Аня", 80)]
```

## Граничные случаи

Пустые списки; равные баллы.
