## Задание

Создай базовый класс Shape с методом area(), который выбрасывает NotImplementedError. Rectangle(width,height) и Circle(radius) переопределяют area.

## Интерфейс

```python
class Shape; class Rectangle(Shape); class Circle(Shape)
```

## Точные правила

Размеры строго положительные; используй math.pi.

## Пример

```text
Rectangle(2,3).area() => 6; Circle(1).area() => pi
```

## Граничные случаи

Нулевые и отрицательные размеры вызывают ValueError.
