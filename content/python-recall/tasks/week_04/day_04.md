## Задание

Создай итератор, который выдаёт числа start,start-1,...,0, затем прекращает работу.

## Интерфейс

```python
class Countdown(start: int)
```

## Точные правила

start >= 0; __iter__ возвращает self; каждое значение выдаётся ровно один раз.

## Пример

```text
list(Countdown(3)) => [3,2,1,0]
```

## Граничные случаи

start=0; повторный list по тому же экземпляру пуст; start<0 вызывает ValueError.

<details><summary>Подсказка (открывай только если застрял)</summary>

__iter__, __next__, raise StopIteration

</details>
