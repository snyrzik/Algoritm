## Задание

Храни количество товаров в классе Inventory. add добавляет, remove списывает и возвращает True/False, get возвращает остаток, items возвращает копию словаря.

## Интерфейс

```python
class Inventory: add(name, count), remove(name, count), get(name), items()
```

## Точные правила

Количество должно быть положительным целым; при недостаточном остатке ничего не менять. После списания до нуля ключ можно оставить со значением 0.

## Пример

```text
add("pen", 4), remove("pen", 2), get("pen") => 2
```

## Граничные случаи

Неизвестный товар, 0, недостаточный запас, защита от изменения внутреннего словаря через items().
