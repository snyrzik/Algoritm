## Задание

Класс BankAccount хранит целочисленный остаток. deposit пополняет, withdraw снимает средства и возвращает True при успехе, False при нехватке.

## Интерфейс

```python
class BankAccount: deposit(amount), withdraw(amount), balance
```

## Точные правила

Начальный баланс >= 0. Любое amount <= 0 вызывает ValueError. Свойство balance доступно только для чтения.

## Пример

```text
BankAccount(100), deposit(50), withdraw(70) => balance == 80
```

## Граничные случаи

Недостаточно денег; снятие нуля; отрицательный первоначальный баланс.
