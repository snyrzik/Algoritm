## Задание

Каждый объект содержит name (str), priority (int) и score (int). Верни имена, отсортированные по убыванию priority, затем по убыванию score и по возрастанию name.

## Интерфейс

```python
rank_items(items: list[dict[str, object]]) -> list[str]
```

## Точные правила

Поля гарантированно присутствуют и имеют верный тип. Повторяющиеся имена разрешены.

## Пример

```text
[{"name":"B","priority":1,"score":5},{"name":"A","priority":2,"score":1}] => ["A","B"]
```

## Граничные случаи

Пустой список; равные значения; входной список не изменяется.

<details><summary>Подсказка (открывай только если застрял)</summary>

sorted(items, key=lambda x: (-x["priority"], -x["score"], x["name"]))

</details>
