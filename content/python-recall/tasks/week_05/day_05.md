## Задание

Замени все email по упрощённой модели на [EMAIL]: латинские буквы, цифры, точки, подчёркивания, плюсы и дефисы до @; после @ — доменное имя с точками и буквенным TLD длиной >=2.

## Интерфейс

```python
mask_emails(text: str) -> str
```

## Точные правила

Соседний текст должен сохраняться. Это учебный шаблон, не полная проверка стандарта email.

## Пример

```text
"Пиши на a.b+1@mail.ru и test@example.com!" => "Пиши на [EMAIL] и [EMAIL]!"
```

## Граничные случаи

Не маскируй строку без @ или без доменной зоны.

<details><summary>Подсказка (открывай только если застрял)</summary>

re.sub(pattern, "[EMAIL]", text)

</details>
