## Задание

Найди самую длинную подряд идущую группу одинаковых чисел и верни (начальный индекс, длина).

## Интерфейс

```python
longest_equal_run(values: list[int]) -> tuple[int, int] | None
```

## Точные правила

При равной длине выбирай первую группу. Для пустого списка верни None.

## Пример

```text
[1, 1, 2, 2, 2, 3] => (2, 3)
```

## Граничные случаи

Пустой список; один элемент; все одинаковые.

Перебирай индексы и меняй текущую группу при смене значения.

</details>
