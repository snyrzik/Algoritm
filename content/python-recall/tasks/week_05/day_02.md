## Задание

Из строк с российскими телефонами сделай список уникальных канонических номеров вида +7XXXXXXXXXX.

## Интерфейс

```python
normalize_phones(texts: list[str]) -> list[str]
```

## Точные правила

Принимаются номера из 11 цифр, начинающиеся на 7 или 8, либо +7 и ещё 10 цифр; разрешены пробелы, скобки, дефисы. Любые буквы или другие символы делают строку невалидной. Сохраняй порядок первого появления.

## Пример

```text
["8 (999) 123-45-67", "+7 999 123 45 67", "89991112233"] => ["+79991234567", "+79991112233"]
```

## Граничные случаи

Короткие номера, +8, буквы, пустые значения.

re.fullmatch на допустимые символы, re.sub для цифр

</details>
