## Задание

Посчитай строки, начинающиеся с одного из уровней INFO, WARNING, ERROR, за которым идёт двоеточие и любое сообщение.

## Интерфейс

```python
count_log_levels(lines: list[str]) -> dict[str, int]
```

## Точные правила

Пробелы в начале строки допускаются, регистр строго верхний. Верни словарь со всеми тремя ключами, даже если значение 0.

## Пример

```text
["INFO: start", " ERROR: stop", "DEBUG: hi", "WARNING: slow"] => {"INFO": 1, "WARNING": 1, "ERROR": 1}
```

## Граничные случаи

INFOO:, ERROR без двоеточия не учитывать.

<details><summary>Подсказка (открывай только если застрял)</summary>

re.match(r"^\s*(INFO|WARNING|ERROR):", ...)

</details>
