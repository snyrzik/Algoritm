## Задание

Найди в тексте уникальные идентификаторы строго вида TASK-YYYY-NNN, где Y и N — цифры. Верни в порядке первого появления.

## Интерфейс

```python
find_task_ids(text: str) -> list[str]
```

## Точные правила

Не допускай идентификатор как часть более длинного буквенно-цифрового слова. Регистр только верхний.

## Пример

```text
"TASK-2026-042 и TASK-2026-042, TASK-2025-001" => ["TASK-2026-042", "TASK-2025-001"]
```

## Граничные случаи

TASK-2026-42, XTASK-2026-042, TASK-2026-0421 не засчитывать.
