## Задание

Верни словарь только тех целых чисел, которые встречаются в списке минимум дважды, со значениями — количества появлений.

## Интерфейс

```python
duplicates(values: list[int]) -> dict[int, int]
```

## Точные правила

Не применяй Counter и сторонние библиотеки.

## Пример

```text
[1,2,1,3,2,2] => {1:2,2:3}
```

## Граничные случаи

Пустой список, все уникальны.

<details><summary>Подсказка (открывай только если застрял)</summary>

counts[value] = counts.get(value,0) + 1

</details>
