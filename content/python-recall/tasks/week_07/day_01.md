## Интерфейс

```python
matrix_stats(matrix: list[list[int]]) -> tuple[list[int], list[int], float]
```

## Точные правила

Матрица непустая и прямоугольная, типы — числа; результаты отдай как обычные Python list, list, float.

## Пример

```text
[[1,2,3],[4,5,6]] => ([6,15], [4,5,6], 3.5)
```
