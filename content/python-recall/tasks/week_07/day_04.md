## Задание

Из строк с полями category, price, qty построй DataFrame и вычисли суммарную выручку price * qty по категориям.

## Интерфейс

```python
category_revenue(rows: list[dict[str, object]]) -> dict[str, int]
```

## Точные правила

price и qty — неотрицательные целые; пустой вход возвращает {}; порядок ключей не имеет значения.

## Пример

```text
[{"category":"food","price":10,"qty":3},{"category":"food","price":5,"qty":2}] => {"food":40}
```

## Граничные случаи

Пустые данные; несколько категорий.

<details><summary>Подсказка (открывай только если застрял)</summary>

df["revenue"] = df["price"] * df["qty"]; groupby("category").sum()

</details>
