## Задание

На основе списка записей с полями name, age, city создай DataFrame, оставь людей возраста >= min_age из заданного города.

## Интерфейс

```python
filter_people(rows: list[dict[str, object]], min_age: int, city: str) -> list[str]
```

## Точные правила

Верни имена по алфавиту. Для пустого списка сразу верни []. Поля гарантированно присутствуют.

## Пример

```text
[{"name":"Аня","age":20,"city":"СПб"},{"name":"Олег","age":17,"city":"СПб"}], 18, "СПб" => ["Аня"]
```

## Граничные случаи

Никто не подходит; пустые данные.

df[(df["age"] >= min_age) & (df["city"] == city)]
