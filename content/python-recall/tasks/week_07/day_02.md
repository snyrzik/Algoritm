## Задание

Получив 2D-матрицу пикселей (0–255), прибавь delta, обрезая значения до границ 0–255.

## Интерфейс

```python
adjust_brightness(pixels: list[list[int]], delta: int) -> list[list[int]]
```

## Точные правила

Используй numpy и знаковый целочисленный тип перед сложением, чтобы не было переполнения uint8. Верни вложенные обычные списки.

## Пример

```text
[[0, 100], [250, 255]], delta=10 => [[10,110],[255,255]]
```

## Граничные случаи

delta отрицателен, матрица 1x1. Вход всегда непустой и прямоугольный.

<details><summary>Подсказка (открывай только если застрял)</summary>

np.array(...,dtype=int), np.clip(...,0,255)

</details>
