## Задание

Сложи стоимость корзины, где (цена, количество) — целые неотрицательные числа. Если сумма не меньше threshold, примени процентную скидку.

## Интерфейс

```python
checkout(items: list[tuple[int, int]], threshold: int, discount_percent: int) -> int
```

## Точные правила

Сумма — целое число денежных единиц; округляй итог вниз через //; скидка от 0 до 100 включительно; некорректные элементы не включаются. Порог неотрицателен.

## Пример

```text
[(100, 2), (50, 1)], threshold=200, discount_percent=10 => 225
```

## Граничные случаи

Пустая корзина; сумма точно равна порогу; цена или количество отрицательные.
