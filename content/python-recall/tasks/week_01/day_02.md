## Интерфейс

```python
clean_names(names: list[str]) -> list[str]
```

## Точные правила

Пустые после очистки строки пропускай. Для сравнения дубликатов используй уже нормализованное имя.

## Пример

```text
["  aLICE   smith  ", "Bob", "alice smith", "  "] => ["Alice Smith", "Bob"]
```
