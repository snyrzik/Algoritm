## Задание

Обработай команды BUY товар количество и SELL товар количество. Покупка увеличивает остаток, продажа уменьшает, но только если остатка достаточно. Названия товаров чувствительны к регистру.

## Интерфейс

```python
process_commands(commands: list[str]) -> dict[str, int]
```

## Точные правила

Команда имеет ровно 3 части; количество — положительное целое; испорченную/неизвестную команду пропускай. Товары с нулевым остатком остаются в словаре.

## Пример

```text
["BUY apple 5", "BUY banana 3", "SELL apple 2", "SELL banana 10", "BUY apple 1"] => {"apple": 4, "banana": 3}
```

## Граничные случаи

Пустой список => {}; продажа отсутствующего товара игнорируется; 0 и отрицательные значения не принимаются.

<details><summary>Подсказка (открывай только если застрял)</summary>

dict.get(key, 0), split(), isdigit()

</details>
