## Задание

Найди самый длинный непрерывный строго возрастающий фрагмент числового списка.

## Интерфейс

```python
longest_increasing_run(values: list[int]) -> list[int]
```

## Точные правила

Если несколько фрагментов одинаковой длины, верни первый; для пустого списка верни []. Одинаковые соседние числа разрывают рост.

## Пример

```text
[1, 2, 5, 3, 4, 6, 1] => [1, 2, 5]
```

## Граничные случаи

Один элемент, убывающий список, равные элементы.
