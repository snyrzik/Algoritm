## Задание

Прочитай UTF-8 файл и верни словарь с количеством непустых строк, количеством слов и самым частым словом.

## Интерфейс

```python
file_stats(path: str) -> dict[str, object]
```

## Точные правила

Слова определяются так же, как в задаче 6 (русские/английские буквы). При равенстве частот выбери алфавитно первое; если слов нет, top_word = None.

## Пример

```text
Файл с текстом "Кот кот

Дом!" => {"nonempty_lines": 2, "words": 3, "top_word": "кот"}
```

## Граничные случаи

Пустой файл; отсутствующий файл вызывает FileNotFoundError.

<details><summary>Подсказка (открывай только если застрял)</summary>
