## Задание

Создай два файла: utils.py с тремя функциями и main.py, который импортирует и демонстрирует их. normalize_title убирает лишние пробелы и делает слова с большой буквы; make_slug превращает слова в нижний регистр и соединяет дефисом; initials берёт первые буквы слов.

## Интерфейс

```python
normalize_title(text: str) -> str; make_slug(text: str) -> str; initials(text: str) -> str
```

## Точные правила

Для make_slug допускаются только латинские буквы и цифры, прочие символы разделяют слова; для остальных функций пробел — разделитель.

## Пример

```text
"  Hello   WORLD " => normalize_title: "Hello World", make_slug: "hello-world", initials: "HW"
```

## Граничные случаи

Пустая строка; одинарное слово; знаки препинания в slug.
