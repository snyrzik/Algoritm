## Задание

Прочитай CSV файл с заголовками category,amount, где amount — целое число расходов, и посчитай сумму по каждой категории.

## Интерфейс

```python
expense_totals(path: str) -> dict[str, int]
```

## Точные правила

Пустую категорию и нецелое/отрицательное amount пропускай. Разделитель — запятая, кодировка UTF-8.

## Пример

```text
CSV: category,amount
food,100
taxi,30
food,50 => {"food": 150, "taxi": 30}
```

## Граничные случаи

Только заголовок; неверные числа; пропуски столбцов.

<details><summary>Подсказка (открывай только если застрял)</summary>

csv.DictReader, try/except ValueError

</details>
