## Задание

Сделай консольную программу, которая принимает путь к UTF-8 файлу и необязательный аргумент --top N, после чего выводит первые N непустых строк и их общее количество.

## Интерфейс

```python
count_nonempty_lines(path: str) -> int; main(argv: list[str] | None = None) -> int
```

## Точные правила

По умолчанию N=3; N >= 0, при отрицательном N argparse выдаёт ошибку; строки печатай без завершающего переноса из файла; main возвращает общее количество непустых строк.

## Пример

```text
Файл: "a

b
c
", вызов --top 2 => печать a, b, Total: 3; main возвращает 3
```

## Граничные случаи

Пустой файл, --top 0, отсутствующий путь (возникает FileNotFoundError).
