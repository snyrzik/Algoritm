## Задание

Из UTF-8 текстового файла, где одна запись на строку, прочитай только корректные целые числа.

## Интерфейс

```python
read_integers(path: str) -> list[int]
```

## Точные правила

Пробелы вокруг числа можно удалять; отрицательные числа допустимы; остальные строки пропускай. Порядок сохранить.

## Пример

```text
Файл: "12
abc
 -7 
3.5
" => [12, -7]
```

## Граничные случаи

Пустой файл; пустая строка; FileNotFoundError не подавлять.
