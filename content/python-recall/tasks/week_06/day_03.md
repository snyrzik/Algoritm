## Задание

Прочитай первую HTML-таблицу: каждая строка tr содержит ячейки th/td. Верни содержимое как CSV-текст.

## Интерфейс

```python
html_table_to_csv(html: str) -> str
```

## Точные правила

Пустые строки без ячеек игнорируй; пробелы по краям текста ячеек убрать; все столбцы сохранять, включая пустые ячейки. CSV писать через csv.writer с lineterminator="\n".

## Пример

```text
"<table><tr><th>A</th><th>B</th></tr><tr><td>1</td><td>2</td></tr></table>" => "A,B
1,2
"
```

## Граничные случаи

Нет таблицы => пустая строка; текст с запятой должен корректно экранироваться.
