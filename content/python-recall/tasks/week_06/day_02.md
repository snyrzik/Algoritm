## Задание

Найди все адреса из href локального HTML и верни уникальные абсолютные ссылки http и https в порядке появления.

## Интерфейс

```python
absolute_links(html: str) -> list[str]
```

## Точные правила

Адрес должен иметь схему http/https и непустой netloc. Пробелы вокруг href убирай; относительные ссылки и mailto пропускай.

## Пример

```text
"<a href="https://a.ru">A</a><a href="/x">X</a>" => ["https://a.ru"]
```

## Граничные случаи

Повторы, пустой href, https без домена.
