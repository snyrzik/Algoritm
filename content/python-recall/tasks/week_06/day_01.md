## Задание

В локальной HTML-строке найди все элементы <article class="product">, у каждого прочти текст <h2> и атрибут data-price (целое число).

## Интерфейс

```python
parse_catalog(html: str) -> list[tuple[str, int]]
```

## Точные правила

Пропусти карточки без заголовка, с пустым названием или без положительной цены; никаких сетевых запросов.

## Пример

```text
"<article class="product" data-price="120"><h2>Чай</h2></article>" => [("Чай",120)]
```

## Граничные случаи

Нет карточек, отсутствует price, мусорная цена.
