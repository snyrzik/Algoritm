## Задание

Получи список слов, удали пробелы по краям, нормализуй регистр и посчитай повторы.

## Интерфейс

```python
rank_words(words: list[str]) -> list[tuple[str, int]]
```

## Точные правила

Пустые слова пропускай. Сортируй по убыванию частоты, при равенстве — по алфавиту.

## Пример

```text
[" Cat ", "dog", "cat", "DOG", "fox"] => [("cat",2),("dog",2),("fox",1)]
```

## Граничные случаи

Пустой список; только пробелы; регистр.
