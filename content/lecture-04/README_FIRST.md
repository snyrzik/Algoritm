# C++ Mastery — лекция № 4 «Списки»

Этот комплект продолжает ранее подготовленные **лекции № 1, № 2 (переходную) и № 3**. Он предназначен для **существующего сайта**, а не для разработки нового приложения.

## Основа

Оригинальный PDF преподавателя Е. В. Мясникова «Списки» — **49 слайдов**:

- 2–11: линейные списки, односвязный список, вставка, удаление и поиск;
- 12–23: двусвязный, циклический и ортогональный списки;
- 24–42: STL-контейнеры `vector`, `list`, `deque`;
- 43–49: сложность операций, последний сравнительный слайд.

Готовая авторская теория написана в `lecture-04/LECTURE_04_THEORY.md`. Codex не должен её сочинять заново.

### Самостоятельные проекты

1. `ForwardChain<T>` — односвязный список, удаление, разворот, глубокое копирование.
2. `BidirectionalList<T>` — двусвязный список, операции на концах и внутри, согласованность `prev/next`.
3. `CollectionLab` — безопасная работа с `vector`, `list`, `deque` и аргументация сложности.

**Готовых решений проектов нет.**

## Интеграция

Открой существующий репозиторий C++ Mastery в Codex, передай этот архив и попроси выполнить `lecture-04/CODEX_INSTRUCTIONS.md`.

- Не создавать новый сайт.
- Не менять первые три лекции.
- Не удалять прогресс и решения.
- Не добавлять серверный компилятор.
- Использовать готовую теорию целиком.

## Локальная проверка

Скопируй предоставленный `MAIN_*.cpp` рядом со своим заголовочным файлом `*.hpp`. Команды приведены в `lecture-04/MAIN_SYNTAX_CHECK.md`.

Проверочные `main` используют обычные `assert` и работают с локальным GCC/Clang C++17. Не используй `-DNDEBUG`, чтобы проверки не были отключены.

## Честное различие контекстов

Официальная лабораторная № 1 запрещает STL-контейнеры **в её самостоятельной реализации**, кроме специально разрешённых типов. Это не распространяется на независимую учебную практику по лекции № 4: её третья задача **как раз учит применять STL**. Первые два проекта должны хранить данные в собственных узлах, без подмены их `std::list`.
