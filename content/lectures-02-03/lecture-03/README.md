# Лекция № 3 — Шаблоны, приведение типов и RTTI

> Полный курс по 25 слайдам лекции преподавателя с пояснениями по C++17.

1. Передай Codex `CODEX_INSTRUCTIONS.md` и остальные файлы этой папки для интеграции в существующий сайт.
2. Изучи четыре главы `LECTURE_03_THEORY.md` и их короткие закрепления.
3. Самостоятельно напиши `GenericAlgorithms.h`, `FixedStack.h`, `IStack.h`, `LinkedStack.h` и `PostfixEvaluator.h`.
4. Для отдельной короткой практики по RTTI создай `RttiLab.h`.
5. Проверяй свои классы **локально** с помощью соответствующих `MAIN_*.cpp`.

Конкретные требования к методам, возвращаемым значениям, исключениям и шаблонным параметрам — в `CODEX_INSTRUCTIONS.md`.
