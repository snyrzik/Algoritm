# A3 · AudioBlock

### A3. `AudioBlock` — фиксированная ёмкость и инварианты

**Сюжет:** короткий фрагмент из максимум четырёх стереоотсчётов. Ученик должен написать класс, который хранит массив объектов **без динамического выделения памяти**.

**Контракт:**

- Внутри фиксированный массив из 4 `StereoSample` и текущий размер `std::size_t`.
- Конструктор по умолчанию создаёт пустой блок.
- `size() const`, `empty() const`, `full() const`.
- `append(const StereoSample&)` возвращает `bool`: `true`, если элемент добавлен; `false`, если блок полный. При неудаче блок не меняется.
- Две версии `operator[]`: чтение и изменение, проверка `index < size()`, иначе `std::out_of_range`. Внимание: физически массив 4, но логически допустимы только добавленные элементы.
- `operator()(const ChannelMix&) const` возвращает **новый** `AudioBlock`, применяя микшер ко всем логическим элементам. Исходный блок не изменяется.
- `average_power() const` вычисляет среднюю мощность по формуле: для `n>0`, `sum((L_i*L_i + R_i*R_i)/2)/n`. Для пустого блока возвращает `0.0`.
- Без `std::vector` и без ручной работы с динамической памятью. Обычное копирование объекта должно приводить к независимым значениям отсчётов.

**Контрольные случаи:**

- Пустой блок: `size=0`, `empty=true`, `full=false`, `average_power=0`.
- Добавлены `(1,1)` и `(3,1)`: средняя мощность `(1+5)/2=3`.
- `append` пятого отсчёта возвращает `false`; прежние четыре остаются.
- Попытка `block[0]` для пустого блока бросает исключение.
- После применения микшера размер нового блока тот же, значения изменены, исходные значения сохранены.
- Изменение `copy[0]` после копирования не меняет `original[0]`.
