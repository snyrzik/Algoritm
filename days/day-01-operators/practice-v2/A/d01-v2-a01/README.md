# A1 · StereoSample

### A1. `StereoSample` — значение, арифметика, индексация

**Сюжет:** один момент записи имеет левый и правый каналы. Нужно описать этот объект как полноценный пользовательский тип.

**Контракт:**

- Хранит ровно два значения `double`: `left` и `right`, закрытые от прямого доступа.
- Конструктор по умолчанию создаёт `(0,0)`. Конструктор из двух `double` задаёт значения.
- Константные методы `left()`, `right()` возвращают числа (без изменяемых ссылок).
- `sample[0]` — левый, `sample[1]` — правый канал; доступ по ссылке для изменяемого объекта, для `const` — только чтение. Индекс `>=2` → `std::out_of_range`.
- `a + b`, `a - b`, унарный `-a` действуют покомпонентно, **не изменяя** входные объекты.
- `a += b`, `a -= b` изменяют исходный `a`, поддерживают цепочки.
- `a * k` и `k * a` масштабируют оба канала на `double`; поддержка обоих порядков обязательна.
- `==`/`!=` используют абсолютный допуск `1e-9` для каждой координаты. Допуск документирован, область — конечные числа; избегать сравнения через обрезание до `int`.
- `std::ostream& operator<<` выводит `(left,right)` и поддерживает цепочки.
- Класс копируем обычными механизмами; **не требуется** ручной деструктор и `new`.


**Контрольные случаи:**

- `(2, -1) + (3, 4) = (5,3)`.
- `(2, -1) - (3, 4) = (-1,-5)`.
- `-(2,-1) = (-2,1)`.
- `(1,-2) * 0.5 = (0.5,-1)` с обеих сторон.
- Цепочка `(a += b) += c` меняет `a`, а не временный объект.
- Через `sample[1] = 7.5` меняется правый канал.
- `const StereoSample&` разрешает читать `[]`, но не писать.
- При обращении `sample[2]` бросается `std::out_of_range` и объект не меняется.
