# D03 · Code review 3

Triple поддерживает чтение const-объектов и изменение обычных. Параметр индекса остаётся int; допустимы 0,1,2. Другие значения бросают out_of_range до доступа к памяти.

Сначала объясните характер проблемы в отдельном поле и отметьте затронутые правила. После фиксации разбора исправьте код. Строка с дефектом заранее не отмечается.
