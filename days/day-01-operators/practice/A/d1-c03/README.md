# d1-c03 · A3 · Matrix2x2

Реализуйте Matrix2x2(double a=0,double b=0,double c=0,double d=0), строки (a,b),(c,d). Доступ m(row,col) для std::size_t: double& и const double&; каждая координата должна быть меньше 2, иначе out_of_range. Поддержите +, -, матричное умножение, == и != по точному равенству элементов. Произведения вычисляйте по правилу строка×столбец, не поэлементно. Операнды неизменны.

## Проверки

- Инициализация и доступ
- Арифметика
- Настоящее умножение матриц
- Единица и ноль
- Границы обеих координат
