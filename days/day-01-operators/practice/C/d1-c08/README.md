# d1-c08 · C · Operator Challenge

Реализуйте Vector3 с приватными координатами double и конструктором Vector3(double x=0,double y=0,double z=0). Операции: бинарные + и -, унарные + и -, умножение на double с обеих сторон, == и != (точное сравнение координат), две версии [] с индексом std::size_t. Изменяемая версия возвращает double&, константная — const double&. Индексы вне 0..2 бросают std::out_of_range. Арифметика не меняет операнды. Вывод строго (x,y,z) с обычным форматированием потока, без пробелов и перевода строки. Готовые контейнеры не использовать. Определения размещайте в solution.hpp или в solution.cpp с объявлениями в заголовке.

Реализуйте Polynomial2(double a=0,double b=0,double c=0) для a*x*x+b*x+c. Индексы: p[0]=c, p[1]=b, p[2]=a. Две версии [] возвращают double& / const double&; неверный индекс → out_of_range. Поддержите +, -, унарные + и -, умножение на double с обеих сторон и const-operator()(double). Вывод в поток: [a,b,c] без пробелов. Сравнение == и != — точное по коэффициентам. Арифметика не изменяет операнды. Собственные приватные поля, без STL-контейнеров.

Реализуйте Matrix2x2(double a=0,double b=0,double c=0,double d=0), строки (a,b),(c,d). Доступ m(row,col) для std::size_t: double& и const double&; каждая координата должна быть меньше 2, иначе out_of_range. Поддержите +, -, матричное умножение, == и != по точному равенству элементов. Произведения вычисляйте по правилу строка×столбец, не поэлементно. Операнды неизменны.

Реализуйте Vector3 transform(const Vector3& v,const Matrix2x2& m,const Polynomial2& p): матрица преобразует первые две координаты, третья сохраняется; затем p применяется к каждой из трёх координат. Используйте публичные операторы классов, без доступа к их приватным данным. В notes.md объясните выбор вспомогательных функций.
