# d1-c06 · B3 · Транзакционный ввод Matrix2x2

Реализуйте Matrix2x2(double a=0,double b=0,double c=0,double d=0), строки (a,b),(c,d). Доступ m(row,col) для std::size_t: double& и const double&; каждая координата должна быть меньше 2, иначе out_of_range. Поддержите +, -, матричное умножение, == и != по точному равенству элементов. Произведения вычисляйте по правилу строка×столбец, не поэлементно. Операнды неизменны. Добавьте потоковые << и >>. Формат [[a,b],[c,d]], разрешены пробельные символы вокруг чисел и разделителей. Проверяйте все скобки и запятые. При неполном или неверном вводе устанавливайте failbit и полностью сохраняйте прежнюю матрицу. Чтение заканчивается сразу после последней скобки; следующий объект остаётся доступным. Исключения потока не включайте самостоятельно.

## Проверки

- Инициализация и доступ
- Арифметика
- Настоящее умножение матриц
- Единица и ноль
- Границы обеих координат
- Потоковая цепочка
- Ввод с пробелами и последовательное чтение
- Плохие разделители и неполный ввод
- Некорректное число
