## Закрепление после главы 3 · Класс `FixedHistory`

> **Формат:** одна составная задача на 15–25 минут. Код интерфейса нужно придумать самостоятельно.

Создай класс `FixedHistory`, хранящий **ровно четыре целых значения** в обычном массиве-члене класса. Динамическая память не нужна.

Требования:

1. Конструктор принимает четыре начальных значения.
2. Изменяемый `operator[]` позволяет писать `history[2] = 100`.
3. Константный `operator[]` позволяет читать значения у `const FixedHistory`.
4. `operator()(first, second) const` возвращает сумму двух указанных элементов и по возможности использует уже написанную индексацию.
5. Добавь метод `swap_indices(a, b)`, меняющий местами элементы по двум индексам.
6. Любой недопустимый индекс должен приводить к `std::out_of_range`.
7. Если в `swap_indices` второй индекс некорректен, **ни один элемент не должен измениться**. Предусмотри также случай, когда `a == b`.

**Критерии:** две корректные версии `operator[]`; ссылочные результаты там, где требуется изменение; `const`-корректность; отсутствие копирования массива ради чтения; повторное использование проверок; сохранение состояния при ошибке; правильная работа с одинаковыми индексами.
