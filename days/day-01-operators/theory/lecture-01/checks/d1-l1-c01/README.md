## Закрепление после главы 1 · Класс `ScoreCounter`

> **Формат:** одна самостоятельная задача на 10–25 минут. Решение в теории не показывать. Это проверка понимания главы, **не замена основных упражнений A/B/C**.

Создай класс `ScoreCounter`, который хранит одно целое число очков. Класс нужен для моделирования простого счётчика результатов.

Требования:

1. Поле должно быть закрытым. Создай конструктор со стартовым количеством очков; по умолчанию счётчик должен начинаться с нуля.
2. Предоставь константный метод чтения очков и изменяющий метод, который прибавляет произвольное целое значение.
3. Сделай так, чтобы изменяющий метод можно было вызвать дважды подряд в одном выражении через `.`.
4. Напиши отдельную свободную функцию `higher_score`, принимающую два счётчика и возвращающую `true`, если очков у первого больше. Она не должна изменять или без необходимости копировать объекты.
5. Продемонстрируй, что копирование счётчика создаёт независимый объект: изменение копии не должно изменять оригинал.
6. Покажи, что метод чтения работает для `const ScoreCounter`.

**Критерии проверки:** правильный конструктор и список инициализации; самостоятельный выбор параметров и возвращаемых типов; корректность `const`; независимость копии; работа цепочки методов. Отдельно проверь отсутствие ссылок на локальные переменные.


В test_adapter.hpp привяжите указатели к своим методам чтения и изменения. Имена points/add/seconds — только настройки адаптера: можно выбрать другие имена. Сигнатуры и реализацию вы пишете самостоятельно. Проверки вызывают сами методы, включая их const-корректность и тип результата.
