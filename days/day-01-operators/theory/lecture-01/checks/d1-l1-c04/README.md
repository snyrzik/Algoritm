## Закрепление после главы 4 · Форматируемое время `ClockTime`

> **Формат:** одна самостоятельная задача на 20–30 минут. Не показывать реализацию `operator>>` до попытки.

Создай класс `ClockTime`, представляющий время суток: часы от 0 до 23 и минуты от 0 до 59. Объект не должен существовать в некорректном состоянии.

Требования:

1. Конструктор принимает часы и минуты и проверяет диапазоны. Для некорректных аргументов используй подходящее исключение из `<stdexcept>`.
2. Реализуй `operator<<`, который печатает время в строгом формате `HH:MM`, например `07:05` и `23:59`.
3. Реализуй `operator>>`, читающий тот же формат. Отклоняй неправильные разделители, недопустимые часы и минуты, а также неполные данные.
4. При неудачном чтении установи состояние ошибки входного потока и сохрани **прежнее значение** `ClockTime`.
5. Поддержи цепочки `out << first << " | " << second` и `in >> first >> second`.
6. Проверь вывод через `std::ostringstream`, а ввод через `std::istringstream`.
7. При выборе форматирования объясни, какие манипуляторы могут изменять состояние потока и нужно ли восстанавливать его свойства после собственного оператора.

Обязательные случаи проверки:

- `07:05` — правильное время.
- `23:59` — правильное время.
- `24:00` — недопустимые часы.
- `12:60` — недопустимые минуты.
- `12;30` — неправильный разделитель.
- `12:` — незавершённое значение.
- При каждой ошибке уже существующий объект остаётся неизменным.

**Критерии:** корректная сигнатура обоих операторов; работа с `const`; точный формат с ведущими нулями; устойчивость к ошибкам; корректное состояние потока; отсутствие частичного изменения объекта; тестирование через строковые потоки.


Проверяющий протокол: HH:MM означает ровно две цифры часов, двоеточие и две цифры минут. Начальные пробелы разрешены; последовательное чтение проверяется с пробелом между объектами. Некорректный конструктор должен бросать std::invalid_argument или std::out_of_range. После вывода сохраняются fill, flags и precision исходного потока. В notes.md объясните решение по форматированию.
