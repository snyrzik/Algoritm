# d4-d08 · Проверка динамического типа

as_derived(Base*) возвращает Derived* или nullptr. Разрешён nullptr-вход; неверный динамический тип не должен давать указатель Derived.

В notes.md найдите и объясните причины проблем; исправьте код и пройдите тесты. Не предполагается заранее известное число дефектов. Если фрагмент корректен, объясните почему и сохраните его.

## Проверки

- Успех и неудача
