# d4-c05 · B2 · DynamicStack<T>

Реализуйте template<class T> class DynamicStack как односвязный список с вложенным узлом и владением через new/delete. Full() всегда false. Реализуйте глубокое копирование с сохранением порядка, копирующее присваивание и деструктор. Не используйте STL-контейнеры. Интерфейс стека: bool Push(const T&), bool Pop(T&), bool Get(T&) const, std::size_t Count() const, bool Empty() const, bool Full() const. Pop/Get пустого стека возвращают false, не меняя выходной аргумент; Get не удаляет. Push полного стека возвращает false без изменений. LIFO. Исключения T передаются вызывающему коду. Если копирование T бросает, сохраняются состояние и число элементов (сильная гарантия для Push/Pop/Get; выходной аргумент может быть изменён бросающим присваиванием самого T).

## Проверки

- Пустое состояние
- LIFO и Get
- Повторное использование
- Глубокое копирование и порядок
- Жизнь пользовательских объектов
- Исключение при вставке
- Неудачное копирование цепочки
