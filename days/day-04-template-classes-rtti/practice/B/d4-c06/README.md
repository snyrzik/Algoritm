# d4-c06 · B3 · Специализация char*

Реализуйте первичный template<class T> class TextStack (можно только объявление) и полную специализацию TextStack<char*>. Методы: bool Push(const char*), bool Pop(), const char* Get() const, size_t Count() const, bool Empty() const. Push копирует строку в собственный new[]-буфер; nullptr → invalid_argument. Get пустого → out_of_range; указатель Get заимствован до изменения/уничтожения стека. Pop удаляет строку и возвращает false на пустом. Реализуйте глубокое копирование стека, присваивание и освобождение всех узлов/строк. Внутри — собственный связный список.

## Проверки

- Глубокая копия входного буфера
- LIFO и копия стека
- Пустой стек и nullptr
- Присваивание и самоприсваивание
- Разрушение и пустая строка
