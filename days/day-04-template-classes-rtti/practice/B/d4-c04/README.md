# d4-c04 · B1 · AbstractStack<T>

Реализуйте template<class T> class AbstractStack с чисто виртуальными методами следующего контракта и виртуальным деструктором. Для проверки создайте template<class T> class SingleStack : public AbstractStack<T> вместимостью 1, использующий override. Интерфейс стека: bool Push(const T&), bool Pop(T&), bool Get(T&) const, std::size_t Count() const, bool Empty() const, bool Full() const. Pop/Get пустого стека возвращают false, не меняя выходной аргумент; Get не удаляет. Push полного стека возвращает false без изменений. LIFO. Исключения T передаются вызывающему коду. Если копирование T бросает, сохраняются состояние и число элементов (сильная гарантия для Push/Pop/Get; выходной аргумент может быть изменён бросающим присваиванием самого T).

## Проверки

- Абстрактность и виртуальный деструктор
- Виртуальные вызовы
- Удаление через базу
