# d4-c08 · C · Stack Architecture Challenge

Реализуйте AbstractStack<T> с виртуальными методами стека и деструктором. Обе реализации ниже должны публично наследовать интерфейс и использовать override.

Реализуйте template<class T,int Size=256> class TFixedStack на собственном массиве фиксированной вместимости, Size>0 (static_assert). Элементы T должны быть default-constructible, копируемы и присваиваемы. Не менее трёх методов определите вне класса. Интерфейс стека: bool Push(const T&), bool Pop(T&), bool Get(T&) const, std::size_t Count() const, bool Empty() const, bool Full() const. Pop/Get пустого стека возвращают false, не меняя выходной аргумент; Get не удаляет. Push полного стека возвращает false без изменений. LIFO. Исключения T передаются вызывающему коду. Если копирование T бросает, сохраняются состояние и число элементов (сильная гарантия для Push/Pop/Get; выходной аргумент может быть изменён бросающим присваиванием самого T).

Реализуйте template<class T> class DynamicStack как односвязный список с вложенным узлом и владением через new/delete. Full() всегда false. Реализуйте глубокое копирование с сохранением порядка, копирующее присваивание и деструктор. Не используйте STL-контейнеры. Интерфейс стека: bool Push(const T&), bool Pop(T&), bool Get(T&) const, std::size_t Count() const, bool Empty() const, bool Full() const. Pop/Get пустого стека возвращают false, не меняя выходной аргумент; Get не удаляет. Push полного стека возвращает false без изменений. LIFO. Исключения T передаются вызывающему коду. Если копирование T бросает, сохраняются состояние и число элементов (сильная гарантия для Push/Pop/Get; выходной аргумент может быть изменён бросающим присваиванием самого T).

Добавьте template<class T> bool round_trip(AbstractStack<T>& stack,const T& a,const T& b,T& first,T& second): предусловие — стек пустой с местом хотя бы для двух элементов. Push(a), Push(b), затем Pop(first), Pop(second); true только при успехе всех операций. Нельзя определять конкретный тип через RTTI. В notes.md объясните полиморфное уничтожение.
