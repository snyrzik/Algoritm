# d4-c03 · A3 · TFixedStack<T, Size>

Реализуйте template<class T,int Size=256> class TFixedStack на собственном массиве фиксированной вместимости, Size>0 (static_assert). Элементы T должны быть default-constructible, копируемы и присваиваемы. Не менее трёх методов определите вне класса. Интерфейс стека: bool Push(const T&), bool Pop(T&), bool Get(T&) const, std::size_t Count() const, bool Empty() const, bool Full() const. Pop/Get пустого стека возвращают false, не меняя выходной аргумент; Get не удаляет. Push полного стека возвращает false без изменений. LIFO. Исключения T передаются вызывающему коду. Если копирование T бросает, сохраняются состояние и число элементов (сильная гарантия для Push/Pop/Get; выходной аргумент может быть изменён бросающим присваиванием самого T).

## Проверки

- Пустое состояние
- LIFO и Get
- Повторное использование
- Полный стек
- Копирование и тип string
- Исключение при Push
