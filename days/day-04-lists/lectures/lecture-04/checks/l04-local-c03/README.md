### Самостоятельное закрепление после главы 3

**«Найди контейнер и исправь обход».** Даны три сценария: журнал измерений с частым доступом по индексу, список задач со стабильными итераторами и очередь с добавлением на оба конца. Нужно выбрать контейнер и обосновать; затем исправить два небольших фрагмента: один с использованием недействительного итератора после изменения `vector`, другой с попыткой писать `list[i]`. Одно объединённое закрепление главы, без реализации основного проекта на STL.

## Самостоятельная попытка

Выберите контейнер и обоснуйте компромиссы в трёх ситуациях:

1. Часто читать по индексу и дописывать в конец.
2. Часто вставлять и удалять при уже известной позиции, сохраняя ссылки на другие элементы.
3. Работать с обоими концами и иногда читать по индексу.

Исправьте два коротких ошибочных фрагмента. Объясните, когда и почему сохранённый итератор становится недействительным.

```cpp
std::list<int> values{10, 20, 30};
std::cout << values[1]; // Требуется корректный способ доступа.
```

```cpp
std::vector<int> values{10, 20, 30};
auto saved = values.begin();
values.push_back(40); // Ёмкости может не хватить.
std::cout << *saved;
```

Названия контейнеров без объяснения и исправленных фрагментов недостаточны.
