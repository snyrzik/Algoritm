## Самостоятельная попытка

Для каждого фрагмента назовите размер входа, худший случай (либо амортизированную стоимость), число существенных шагов и возможную инвалидацию итераторов. Предполагаются корректные диапазоны; для поиска минимума `n > 0`.

// 1. Индексирование, 0 <= index < n.
