### Самостоятельное закрепление после главы 1

**«Найди ошибку в последовательности указателей».** В интерфейсе покажи функцию добавления узла в начало и функцию удаления головы с тремя намеренными ошибками порядка действий и обработки пустого списка. Нужно объяснить, какое состояние памяти возникает после каждой строки, исправить функции и показать результат для пустого, одноэлементного и трёхэлементного списка. Не выдавай решений автоматически. Это **одно** закрепление главы, а не отдельный набор мелких заданий.

## Самостоятельная попытка

Разберите намеренно ошибочные фрагменты. Не запускайте их с неверными указателями: сначала проследите состояние памяти на бумаге.

```cpp
struct Node { int value; Node* next; };
void push_front(Node*& head, int value) {
    head = new Node{value, nullptr};
    head->next = head;
}
int pop_front(Node*& head) {
    int value = head->value;
    delete head;
    head = head->next;
    return value;
}
```

Объясните потерю старой цепочки, возможное обращение после освобождения и поведение на пустом списке. Исправьте порядок действий самостоятельно. Покажите состояния для пустого, одноэлементного, двухэлементного и трёхэлементного списка; сформулируйте инвариант после каждой строки.
