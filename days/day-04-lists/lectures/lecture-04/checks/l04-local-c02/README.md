### Самостоятельное закрепление после главы 2

**«Почини четыре связи».** Дано три узла двусвязного списка и частично написанная вставка нового узла между первым и вторым. Затем показано удаление головы и последнего элемента. Ученик должен восстановить корректные связи, объяснить граничные случаи и перечислить инварианты, которые следует проверить после каждой операции. Одно небольшое составное упражнение с кодом и схемой; не выдавать реализацию основного `BidirectionalList<T>`.

## Самостоятельная попытка

Исходное состояние:

```text
head -> [10] <-> [20] <-> [30] <- tail
```

Вставьте `15` перед вторым узлом. Заполните четыре изменения связей в 6–12 строках собственного кода, затем удалите первую вершину. Изобразите все `prev/next` после каждой операции. Отдельно покажите удаление последнего и единственного узла: что происходит с `head`, `tail` и размером? Не пишите полный класс проекта.

```cpp
// left указывает на 10, right на 20, added — новый узел со значением 15.
// Запишите четыре необходимые связи самостоятельно.
// Затем запишите удаление головы с проверкой пустого состояния.
```
