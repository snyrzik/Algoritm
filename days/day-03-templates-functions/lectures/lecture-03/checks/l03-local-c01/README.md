### Закрепление 1 — «Что компилятор должен вывести?»

**Формат:** одна составная самостоятельная проверка, около 15–25 минут.

Дан шаблон функции с единым `T`, объявленный учеником самостоятельно. Нужно:

1. Вызвать его с двумя `int` и двумя `double`.
2. Объяснить тип `T` для каждого вызова.
3. Вызвать с `double` и `int`, зафиксировать реальную ошибку компилятора.
4. Исправить вызов двумя способами без изменения шаблона.
5. Привести пример, когда выбор `T = int` вместо `T = double` меняет математический результат.
6. Кратко объяснить, какие операции должны поддерживать пользовательские типы, чтобы подойти для шаблона.

Не подставлять заранее все сигнатуры: проверка нацелена на самостоятельное восстановление синтаксиса.
