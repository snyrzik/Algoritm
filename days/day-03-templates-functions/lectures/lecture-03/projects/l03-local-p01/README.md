## Проект 1. Шаблонные алгоритмы и строки

Самостоятельно напишите `GenericAlgorithms.h`. Готовый `MAIN_GENERIC_FUNCTIONS.cpp` доступен для локальной проверки; реализации алгоритмов в нём нет.

Самостоятельно напишите заголовочный файл `GenericAlgorithms.h` с:

```cpp
template <typename T>
T maximum(T a, T b);

template <typename T>
void swap_values(T& a, T& b);

template <typename T>
T minimum_of_three(T a, T b, T c);

template <typename T>
std::size_t index_of_min(const T* data, std::size_t size);
```

Дополнительно:

1. **Полная специализация** `maximum<const char*>` для лексикографического сравнения C-строк через `std::strcmp`.
2. **Обычная перегрузка** `const char* minimum_value(const char*, const char*)`, тоже сравнивающая содержимое строк.
3. Для `index_of_min`: `nullptr` вызывает `std::invalid_argument`; при ненулевом указателе и `size == 0` — `std::out_of_range`; при повторяющемся минимуме возвращается **индекс первого вхождения**.
4. `swap_values` меняет исходные объекты и работает с пользовательским копируемым классом; самоприменение `swap_values(x, x)` не повреждает `x`.
5. `minimum_of_three` обрабатывает случаи равенства и всегда возвращает значение для указанных в условиях поддерживаемых типов.
6. `maximum` для обычного `T` требует поддержки `operator<`; не делай вид, что он подходит к любому возможному типу. В варианте с одним `T` смешанные аргументы не обязаны выводиться автоматически.

Согласование интерфейса: отдельно показать примеры вызовов из `main`, но **не раскрывать алгоритм**. Пользователь должен сам написать `template`, `template <>`, нужные параметры и возвращаемые типы. Эта работа специально закрепляет различие между шаблоном, обычной перегрузкой и специализацией.
