# d3-c06 · B1 · String Overload

Реализуйте maximum(T,T) и отдельную обычную перегрузку maximum(const char*,const char*). Строки сравниваются через strcmp; равенство возвращает первый аргумент, nullptr → invalid_argument. Разберите отличие перегрузки от специализации в notes.md.

## Проверки

- int, double и char
- Равенство и явный тип
- Пользовательский тип только с <
- Содержимое вместо адресов
- Равные и пустые строки
- nullptr
