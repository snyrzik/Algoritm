# d3-c07 · B2 · String Specialization

Реализуйте maximum(T,T) и полную специализацию для const char*. Сравнение через strcmp, при равенстве первый указатель, nullptr → invalid_argument. Явный вызов maximum<const char*> тоже обязан использовать сравнение содержимого.

## Проверки

- int, double и char
- Равенство и явный тип
- Пользовательский тип только с <
- Содержимое вместо адресов
- Равные и пустые строки
- nullptr
- Явная специализация
