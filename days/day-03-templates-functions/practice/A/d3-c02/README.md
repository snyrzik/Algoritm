# d3-c02 · A2 · maximum<T>

Напишите шаблон T maximum(T a,T b), используя только < и копирование. При равенстве верните a. Тип не должен искусственно ограничиваться числами. В notes.md объясните maximum(2.5,3) и допустимые способы вызова с разными исходными типами.

## Проверки

- int, double и char
- Равенство и явный тип
- Пользовательский тип только с <
