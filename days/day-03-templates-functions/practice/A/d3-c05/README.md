# d3-c05 · A5 · index_of_min<T>

Напишите std::size_t index_of_min(const T* array,std::size_t size). Пустой массив или nullptr → invalid_argument. При нескольких минимумах верните первый индекс. Используйте <.

## Проверки

- Первый и последний минимум
- Первый из равных
- Недопустимые массивы
- Строковый тип
