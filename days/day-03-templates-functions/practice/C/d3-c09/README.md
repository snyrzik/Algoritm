# d3-c09 · C · Generic Utilities Challenge

Напишите три шаблона над обычными массивами: find_first(const T*,size_t,Predicate) -> size_t (индекс первого совпадения, при отсутствии — size); count_if(const T*,size_t,Predicate) -> size_t; swap_at(T*,size_t,size_t i,size_t j) -> void. Для первых двух nullptr допустим лишь при size=0. swap_at: nullptr → invalid_argument, любой индекс>=size → out_of_range, проверка предшествует изменению. Самоперестановка разрешена. Не используйте готовые алгоритмы STL. Сигнатуры оформите самостоятельно в соответствии с этими типами результатов.

Дополните набор maximum(T,T), minimum_of_three(T,T,T), index_of_min(const T*,size_t) с контрактами A2/A4/A5, повторёнными здесь: сравнение только <; пустой index_of_min или nullptr → invalid_argument, при равных минимумах первый индекс. Добавьте Polynomial2 по контракту ниже. Используйте Polynomial2 в find_first/count_if/swap_at по коэффициентам, не вводя искусственный порядок многочленов.

Реализуйте Polynomial2(double a=0,double b=0,double c=0) для a*x*x+b*x+c. Индексы: p[0]=c, p[1]=b, p[2]=a. Две версии [] возвращают double& / const double&; неверный индекс → out_of_range. Поддержите +, -, унарные + и -, умножение на double с обеих сторон и const-operator()(double). Вывод в поток: [a,b,c] без пробелов. Сравнение == и != — точное по коэффициентам. Арифметика не изменяет операнды. Собственные приватные поля, без STL-контейнеров.
