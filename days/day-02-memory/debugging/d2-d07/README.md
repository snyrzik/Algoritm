# d2-d07 · Сдвиг с нулём

erase_prefix(char*,size_t) удаляет первые count символов C-строки на месте. nullptr → invalid_argument; count>strlen → out_of_range без изменения.

В notes.md найдите и объясните причины проблем; исправьте код и пройдите тесты. Не предполагается заранее известное число дефектов. Если фрагмент корректен, объясните почему и сохраните его.

## Проверки

- Правильный ноль
- Ошибки
