# d2-d04 · Порядок замены

replace_copy(char*&,const char*) заменяет владеющий new[]-буфер независимой копией. Источник может быть target+1, nullptr запрещён. При ошибке старый буфер сохраняется.

В notes.md найдите и объясните причины проблем; исправьте код и пройдите тесты. Не предполагается заранее известное число дефектов. Если фрагмент корректен, объясните почему и сохраните его.

## Проверки

- Самоалиасинг
- Отказ выделения
