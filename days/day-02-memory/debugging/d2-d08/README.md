# d2-d08 · Самоконкатенация

append(char*& target,const char* other) добавляет other к владеющему target. Поддержите other==target и указатель внутрь target. nullptr → invalid_argument; сильная гарантия, переполнение → length_error.

В notes.md найдите и объясните причины проблем; исправьте код и пройдите тесты. Не предполагается заранее известное число дефектов. Если фрагмент корректен, объясните почему и сохраните его.

## Проверки

- s += s
- Внутренний указатель
