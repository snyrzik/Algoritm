# d2-d02 · Освобождение ресурса

dispose(int*&) освобождает массив new[] и обнуляет исходный указатель. Повторное освобождение допустимо.

В notes.md найдите и объясните причины проблем; исправьте код и пройдите тесты. Не предполагается заранее известное число дефектов. Если фрагмент корректен, объясните почему и сохраните его.

## Проверки

- Обнуление и повторный вызов
