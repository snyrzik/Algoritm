### Закрепление 4 — «Разбор ошибки без запуска»

**Формат:** анализ и исправление частичной функции, примерно 20–25 минут.

У ученика есть `CMyString` с корректными `m_data` и `m_size` и неполная реализация изменения строки. Функция проверяет только `count <= m_size` и использует `std::strlen` после выполнения сдвига.

Требуется:

1. Найти некорректный диапазон, который такая проверка пропустит.
2. Объяснить, почему `std::size_t` требует особого внимания к вычитанию и сложению.
3. Написать правильную проверку интервала.
4. Объяснить, когда нужен `memmove`.
5. Объяснить, почему не нужно заново искать длину C-строки, если актуальная логическая длина уже хранится в объекте.

Это закрепление не заменяет самостоятельные проекты: полные реализации методов остаются в разделе практики.
