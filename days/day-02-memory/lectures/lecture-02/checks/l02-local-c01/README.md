### Закрепление 1 — «Один буфер, три операции»

**Формат:** короткая программа, примерно 15–25 минут.

Есть изменяемый `char buffer[32]`, изначально содержащий `"warm-water"`.

1. Определи `strlen` и `sizeof` для массива.
2. С помощью `memmove` самостоятельно удали из строки дефис, сохранив завершающий ноль.
3. Через `strcmp` проверь результат на равенство строке `"warmwater"`.
4. Объясни, почему здесь нельзя бездумно подставить `memcpy`.
5. Придумай вариант, где исходный буфер слишком мал для добавления ещё одного слова, и сформулируй проверку, которую нужно выполнить **до** операции добавления.

Не выдавать готовую последовательность копирования и длину переноса; это и есть упражнение. Проверка должна оценивать и код, и текстовое объяснение.
