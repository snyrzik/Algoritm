### Закрепление 2 — «Кому принадлежит массив?»

**Формат:** исправление частичной реализации и объяснение, примерно 20–30 минут.

Дан маленький класс `IntBuffer` с сырым массивом `int*`, длиной, деструктором и некорректным копированием. В двух объектах после копии оказывается один и тот же адрес.

Требуется:

1. Найти два независимых сценария ошибок времени жизни.
2. Исправить конструктор копирования и оператор присваивания.
3. Сохранить правильность при `x = x`.
4. Объяснить схему владения до и после копирования.
5. Проверить, что изменение копии не меняет оригинал.

Стартовый код должен быть коротким, намеренно неполным. **Не выдавай полностью работающий ресурсный класс**, потому что пользователь должен написать исправления сам.
