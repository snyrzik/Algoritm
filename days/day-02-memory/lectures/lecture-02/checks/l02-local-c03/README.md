### Закрепление 3 — «Безопасный диапазон»

**Формат:** одна функция плюс короткое объяснение, 15–20 минут.

Реализуй самостоятельно функцию `checked_access` для массива `int`, которая:

- принимает указатель, размер и индекс;
- не изменяет массив;
- бросает `std::invalid_argument` при `nullptr`;
- бросает `std::out_of_range` при индексе за границей;
- возвращает обычный `int` при корректном доступе.

Дополнительно объясни, почему `std::size_t index < 0` не является полезной проверкой. Проверь два ошибочных вызова **в двух отдельных `try/catch`**, чтобы оба случая действительно выполнились.
