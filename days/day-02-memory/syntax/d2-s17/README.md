# d2-s17 · Сохранение при неудаче

Напишите replace_copy(char*& target,const char* source). target владеет new[]-строкой. Сначала подготовьте новую копию, затем замените ресурс. nullptr → invalid_argument, target при ошибке неизменен; источник может равняться target+1.

## Проверки

- Контракт и граничные значения
