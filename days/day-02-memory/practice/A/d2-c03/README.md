# d2-c03 · A3 · CMyString Fundamentals

Создайте CMyString на собственном динамическом массиве new char[], без std::string или готовых контейнеров в реализации хранения. Обязательны: пустой конструктор, explicit-конструктор из const char*, правило трёх, size() const -> std::size_t, c_str() const -> const char*, две версии [] (char& и const char&), ==, != по содержимому. nullptr в конструкторе → invalid_argument. Индексы [0,size()) доступны; остальные → out_of_range. Пустая строка имеет валидный c_str() с нулём. Копии независимы, самоприсваивание допустимо, присваивание возвращает CMyString&. При неудаче копирования исходное состояние сохраняется. Все размеры включают место для нуля; переполнение → length_error.

## Проверки

- Пустая строка
- Буфер и ноль
- Глубокая копия
- Присваивание и самоприсваивание
- Независимое время жизни
- Неверные аргументы
- Сравнения
- Повторные циклы владения
- Отказ выделения при присваивании
