# d2-c02 · A2 · BadText Repair

Исправьте данный BadText, самостоятельно определив дефекты. Добавьте правило трёх, c_str() const, char& operator[](size_t) с проверкой границ. nullptr → invalid_argument. Строка должна владеть независимым буфером. Объясните причины дефектов в notes.md. Исходный небезопасный код не запускается без ASan.

## Проверки

- Независимость копий
- Присваивание и время жизни
- Пустая строка
- Ошибки
- Цикл владения
