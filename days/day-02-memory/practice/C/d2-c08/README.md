# d2-c08 · C · Resource Safety Challenge

Создайте CMyString на собственном динамическом массиве new char[], без std::string или готовых контейнеров в реализации хранения. Обязательны: пустой конструктор, explicit-конструктор из const char*, правило трёх, size() const -> std::size_t, c_str() const -> const char*, две версии [] (char& и const char&), ==, != по содержимому. nullptr в конструкторе → invalid_argument. Индексы [0,size()) доступны; остальные → out_of_range. Пустая строка имеет валидный c_str() с нулём. Копии независимы, самоприсваивание допустимо, присваивание возвращает CMyString&. При неудаче копирования исходное состояние сохраняется. Все размеры включают место для нуля; переполнение → length_error. Добавьте +, += для CMyString, унарный ! (обратная копия), operator^(int repeats) (повторение), потоковые << и >>. repeats<0 → invalid_argument, переполнение size()*repeats+1 → length_error. += поддерживает s+=s и возвращает ссылку. Ввод >> читает один токен, пропускает начальные пробелы; при ошибке объект неизменен. Пустые строки поддерживаются. Добавьте explicit operator const char*() const; в notes.md сравните явное и неявное преобразования и риски времени жизни. Добавьте void erase(std::size_t position,std::size_t count). Допустим position<=size и count<=size-position, иначе out_of_range без изменения строки. count=0 допустим, в том числе erase(size(),0). Нельзя перевыделять память: адрес c_str() сохраняется. Сдвиг сохраняет завершающий ноль. Добавьте void replace_range(std::size_t position,std::size_t count,const char* replacement). Диапазон как в erase, nullptr → invalid_argument. Поддержите самоперекрытие, укорочение и удлинение, пустую вставку. Переполнение нового размера → length_error до выделения памяти. Сильная гарантия: при исключении исходная строка сохраняется. Контрольный пример: "ABCDE", replace_range(1,2,c_str()+3) → "ADEDE". Исправьте исходный частичный класс и доведите до полного контракта. В notes.md опишите инвариант и точки, где может возникнуть исключение. Не используйте STL-контейнеры для хранения.

- Неверные аргументы
- Сравнения
- Повторные циклы владения
- Отказ выделения при присваивании
- Конкатенация и алиасинг
- Обратный порядок
- Повторение
- Вывод и преобразование
- Ввод и сохранение при ошибке
- Удаление середины без аллокации
- Удаление конца и всей строки
- Нулевой диапазон
- Неверный диапазон
- Самоперекрытие
- Укорочение и удлинение
