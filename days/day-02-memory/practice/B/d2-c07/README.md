# d2-c07 · B4 · replace_range

Создайте CMyString на собственном динамическом массиве new char[], без std::string или готовых контейнеров в реализации хранения. Обязательны: пустой конструктор, explicit-конструктор из const char*, правило трёх, size() const -> std::size_t, c_str() const -> const char*, две версии [] (char& и const char&), ==, != по содержимому. nullptr в конструкторе → invalid_argument. Индексы [0,size()) доступны; остальные → out_of_range. Пустая строка имеет валидный c_str() с нулём. Копии независимы, самоприсваивание допустимо, присваивание возвращает CMyString&. При неудаче копирования исходное состояние сохраняется. Все размеры включают место для нуля; переполнение → length_error. Добавьте void replace_range(std::size_t position,std::size_t count,const char* replacement). Диапазон как в erase, nullptr → invalid_argument. Поддержите самоперекрытие, укорочение и удлинение, пустую вставку. Переполнение нового размера → length_error до выделения памяти. Сильная гарантия: при исключении исходная строка сохраняется. Контрольный пример: "ABCDE", replace_range(1,2,c_str()+3) → "ADEDE".

## Проверки

- Пустая строка
- Буфер и ноль
- Глубокая копия
- Присваивание и самоприсваивание
- Независимое время жизни
- Неверные аргументы
- Сравнения
- Повторные циклы владения
- Отказ выделения при присваивании
- Самоперекрытие
- Укорочение и удлинение
- Полная замена и вставка в конец
- Ошибки не меняют объект
- Отказ выделения и откат
