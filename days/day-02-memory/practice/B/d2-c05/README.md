# d2-c05 · B2 · Variadic Substring

Создайте CMyString на собственном динамическом массиве new char[], без std::string или готовых контейнеров в реализации хранения. Обязательны: пустой конструктор, explicit-конструктор из const char*, правило трёх, size() const -> std::size_t, c_str() const -> const char*, две версии [] (char& и const char&), ==, != по содержимому. nullptr в конструкторе → invalid_argument. Индексы [0,size()) доступны; остальные → out_of_range. Пустая строка имеет валидный c_str() с нулём. Копии независимы, самоприсваивание допустимо, присваивание возвращает CMyString&. При неудаче копирования исходное состояние сохраняется. Все размеры включают место для нуля; переполнение → length_error. Добавьте CMyString operator()(int count,...) const. count задаёт число следующих индексов, каждый передаётся как int. count<0 → invalid_argument, неверный индекс → out_of_range. count=0 → пустая строка. Число переданных аргументов должно соответствовать count (предусловие). Используйте cstdarg, не арифметику адреса count. Исходная строка неизменна.

## Проверки

- Пустая строка
- Буфер и ноль
- Глубокая копия
- Присваивание и самоприсваивание
- Независимое время жизни
- Неверные аргументы
- Сравнения
- Повторные циклы владения
- Отказ выделения при присваивании
- Выборка face
- Пустая и повторная выборки
- Некорректные аргументы
