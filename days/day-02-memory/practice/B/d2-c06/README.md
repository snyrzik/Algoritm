# d2-c06 · B3 · erase

Создайте CMyString на собственном динамическом массиве new char[], без std::string или готовых контейнеров в реализации хранения. Обязательны: пустой конструктор, explicit-конструктор из const char*, правило трёх, size() const -> std::size_t, c_str() const -> const char*, две версии [] (char& и const char&), ==, != по содержимому. nullptr в конструкторе → invalid_argument. Индексы [0,size()) доступны; остальные → out_of_range. Пустая строка имеет валидный c_str() с нулём. Копии независимы, самоприсваивание допустимо, присваивание возвращает CMyString&. При неудаче копирования исходное состояние сохраняется. Все размеры включают место для нуля; переполнение → length_error. Добавьте void erase(std::size_t position,std::size_t count). Допустим position<=size и count<=size-position, иначе out_of_range без изменения строки. count=0 допустим, в том числе erase(size(),0). Нельзя перевыделять память: адрес c_str() сохраняется. Сдвиг сохраняет завершающий ноль.

## Проверки

- Пустая строка
- Буфер и ноль
- Глубокая копия
- Присваивание и самоприсваивание
- Независимое время жизни
- Неверные аргументы
- Сравнения
- Повторные циклы владения
- Отказ выделения при присваивании
- Удаление середины без аллокации
- Удаление конца и всей строки
- Нулевой диапазон
- Неверный диапазон
