# d2-c04 · B1 · CMyString Operators

Создайте CMyString на собственном динамическом массиве new char[], без std::string или готовых контейнеров в реализации хранения. Обязательны: пустой конструктор, explicit-конструктор из const char*, правило трёх, size() const -> std::size_t, c_str() const -> const char*, две версии [] (char& и const char&), ==, != по содержимому. nullptr в конструкторе → invalid_argument. Индексы [0,size()) доступны; остальные → out_of_range. Пустая строка имеет валидный c_str() с нулём. Копии независимы, самоприсваивание допустимо, присваивание возвращает CMyString&. При неудаче копирования исходное состояние сохраняется. Все размеры включают место для нуля; переполнение → length_error. Добавьте +, += для CMyString, унарный ! (обратная копия), operator^(int repeats) (повторение), потоковые << и >>. repeats<0 → invalid_argument, переполнение size()*repeats+1 → length_error. += поддерживает s+=s и возвращает ссылку. Ввод >> читает один токен, пропускает начальные пробелы; при ошибке объект неизменен. Пустые строки поддерживаются. Добавьте explicit operator const char*() const; в notes.md сравните явное и неявное преобразования и риски времени жизни.

## Проверки

- Пустая строка
- Буфер и ноль
- Глубокая копия
- Присваивание и самоприсваивание
- Независимое время жизни
- Неверные аргументы
- Сравнения
- Повторные циклы владения
- Отказ выделения при присваивании
- Конкатенация и алиасинг
- Обратный порядок
- Повторение
- Вывод и преобразование
- Ввод и сохранение при ошибке
