# C++ Mastery

Платформа для изучения C++17 в своём темпе: личный маршрут, поиск, закладки и самостоятельная практика. Полные лекции 1–4 встроены из готовых пакетов без сокращения авторской теории. Лекция 2 — восстановленный переходный модуль о памяти и исключениях; лекция 3 — шаблоны, приведение типов и RTTI. Лекция 4 — списки, STL-контейнеры и сложность. Материалы лекций 1–3 сохранены без изменений.

## Запуск

Нужны Node.js и Python 3. C++-компилятор для запуска сайта не нужен.

```text
npm install
npm start
```

Открыть [«Моё обучение»](http://127.0.0.1:8765/). Начальная страница предлагает первую главу или продолжение с последнего материала. Для разработки интерфейса: `npm run dev`.

В лекции 1 — пять глав и три проекта, в лекции 2 — четыре главы и два проекта, в лекциях 3 и 4 — по четыре главы и три проекта. После каждой главы есть самостоятельное закрепление. «Локальная проверка» даёт исходные авторские main, копирование, скачивание и команды для своей IDE.

## Как сдавать

Напишите реализацию в своей IDE, запустите готовый main и сравните вывод. Затем нажмите «Да, всё совпало» или «Есть расхождения». Сайт сохраняет статус «Отмечено мной», не выполняет C++ и не объявляет автоматическую готовность. Прочтение глав, закрепления и базовые проверки проектов учитываются отдельно.

Проектные main используют обычный `assert`: не задавайте `NDEBUG`. Они проверяют основные сценарии; память, остальные граничные случаи и требования ЛР № 1 проверьте дополнительно. Команды GCC/MinGW, Linux/macOS и инструкция Visual Studio находятся в локальной проверке. Каждый MAIN собирается отдельно.

Необязательные черновики хранятся в `student/day-XX/ID/`, история — в `progress/mastery.sqlite3`. Для проектов первой лекции используются настоящие имена Matrix2x2.hpp, Point2D.hpp, CMyString.hpp, DynamicVector.hpp и соответствующие .cpp. Личные файлы и прогресс исключены из Git.

В интерфейсе доступны четыре лекции и 28 обязательных заданий: 17 закреплений и 11 проектов. Все 240 заданий прежнего практикума модулей 2–5 удалены; их пользовательские файлы и история сохранены и доступны для скачивания в разделе прогресса. Новые проекты имеют собственные ID и ручные результаты. Чтение глав учитывается отдельно.

«Закладки» сохраняют выбранные задания, «Повторение» собирает расхождения и выполненные задания для повторной практики. Сроков прохождения лекций нет. В новых лекциях отдельно сохраняются ошибки, проверка памяти и использованные подсказки. Постфиксный вычислитель — независимый финальный этап проекта LinkedStack, а RTTI — короткое закрепление, не четвёртый большой проект.

## Проверка разработки

```text
npm run build
npm test
npm run test:browser
npm run test:platform-browser
npm run test:lectures-browser
npm run test:lecture04-browser
```

Обычные тесты не требуют C++. Необязательные `npm run test:manual-mains` и `npm run test:lecture-mains` проверяют синтаксис 8 main первой лекции и 10 main лекций 2–4 по объявлениям API в изолированных временных каталогах. Они не запускают пользовательские решения и не вызываются сайтом. `npm run prepare:lectures` пересоздаёт условия лекций 2–3, не перезаписывая ученические файлы.
