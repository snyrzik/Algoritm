# C++ Mastery

Пятидневный практикум C++17: 288 основных заданий и четыре закрепления теории. Программные задания сдаются самостоятельной отметкой после сравнения результата с готовым `main`. Встроенный компилятор и настройка его окружения не требуются.

## Запуск

Для сайта нужны Node.js 22.12+ и Python 3.10+.

```powershell
cd C:\HTLLub\cpp-mastery
npm install
npm start
```

Откройте <http://127.0.0.1:8765/#/day/1>. Режим разработки: `npm run dev`. Остановка — Ctrl+C в терминале запуска.

## Как сдавать

1. Прочитайте условие и напишите решение в своей обычной среде C++.
2. Посмотрите список обычных, граничных и ошибочных случаев.
3. Нажмите **«Показать main для проверки»**. Скопируйте или скачайте готовый файл; при необходимости скачайте ZIP со своими исходниками и нужными заголовками.
4. Запустите пример у себя и сравните вывод с ожидаемым. Для консольного проекта даны отдельные входные сценарии, вывод и поведение при ошибке.
5. Отметьте **«Да, всё совпало»** или **«Есть расхождения»**. Результат можно поменять позже.

«Проверено мной» — самостоятельная отметка пользователя. Она сохраняется в истории и учитывается в прогрессе. Сайт не запускает ваш C++-код. Вопросы с вариантами ответа и предсказание вывода проверяются на сайте.

## Курс

| День | Тема | Программные задания |
|---|---|---|
| 1 | StereoLab: StereoSample, ChannelMix, AudioBlock и потоки | S14, D6, A3, B2, C1; четыре закрепления лекции отдельно |
| 2 | C-строки, CMyString, владение памятью и исключения | Синтаксис, исправления и практика A/B/C |
| 3 | Шаблоны функций, перегрузки и специализации | Синтаксис, исправления и алгоритмы |
| 4 | Шаблоны классов, стеки, полиморфизм и RTTI | Синтаксис, исправления и архитектура |
| 5 | Итоговый экзамен и TSequence | Смешанные вопросы и самостоятельная работа |

Готовые проверочные mains и ожидаемые результаты доступны для всех 171 программного задания. Переход между днями свободный. Баллы Дня 1 сохраняют пропорции из ТЗ: 130 возможных баллов; программные задания засчитываются по отметке пользователя.

## Файлы и прогресс

- Встроенный черновик решения доступен по желанию. Он синхронизируется с `student/day-XX/ID/`; можно редактировать те же файлы в IDE.
- В B/C StereoLab архив проверки включает ваши сохранённые компоненты A1–A3 и B1–B2. Для автономной проверки A2/A3 предоставляются минимальные вспомогательные заголовки.
- История и снимки хранятся в `progress/mastery.sqlite3`. Личные решения и прогресс игнорируются Git.
- После создания нового пустого профиля устаревшие браузерные черновики удаляются при загрузке сайта.
- Резервная копия ваших результатов — папки `student/` и `progress/`.

Сброс учебного профиля описан в [проверке реализации](docs/verification.md). Остановите сервер перед сбросом.

## Проверка платформы

```text
npm run build
npm test
npm run test:browser
npm run test:theory-browser
npm run test:day01-browser
```

Обычные тесты платформы не требуют C++-компилятора и используют временный профиль. Для разработчика отдельно доступен `npm run test:manual-mains`: он при наличии компилятора проверяет готовые mains на контрольных реализациях. Этот инструмент не вызывается при работе сайта.

Подробности: [самостоятельная проверка](docs/self-check.md), [StereoLab](docs/day01-stereolab-v2.md), [лекция Дня 1](docs/day01-theory.md).
