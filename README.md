# C++ Mastery

Платформа для изучения C++17 в своём темпе: программа из пяти модулей, личный маршрут, поиск, закладки и самостоятельная практика. Первая лекция полностью основана на `CppMastery_Lecture01_ReadyPack.zip`: пять авторских глав, пять закреплений и три проекта — Matrix2x2 + Point2D, CMyString, DynamicVector. Учебное содержание остальных модулей сохранено.

## Запуск

Нужны Node.js и Python 3. C++-компилятор для запуска сайта не нужен.

```text
npm install
npm start
```

Открыть [«Моё обучение»](http://127.0.0.1:8765/). Начальная страница предлагает первую главу или продолжение с последнего материала. Для разработки интерфейса: `npm run dev`.

Во вкладке «Теория» доступны пять глав с исходными примерами, схемами памяти и закреплениями. «Практика» содержит три самостоятельных проекта с этапами и точным API. «Локальная проверка» даёт авторские main.cpp, копирование, скачивание и команды для своей IDE.

## Как сдавать

Напишите реализацию в своей IDE, запустите готовый main и сравните вывод. Затем нажмите «Да, всё совпало» или «Есть расхождения». Сайт сохраняет статус «Отмечено мной», не выполняет C++ и не объявляет автоматическую готовность. Прочтение глав, закрепления и базовые проверки проектов учитываются отдельно.

Три проектных main используют обычный `assert`: не задавайте `NDEBUG`. Они проверяют основные сценарии; память, остальные граничные случаи и требования ЛР № 1 проверьте дополнительно. Команды GCC/MinGW, Linux/macOS и инструкция Visual Studio находятся в локальной проверке.

Необязательные черновики хранятся в `student/day-XX/ID/`, история — в `progress/mastery.sqlite3`. Для проектов первой лекции используются настоящие имена Matrix2x2.hpp, Point2D.hpp, CMyString.hpp, DynamicVector.hpp и соответствующие .cpp. Личные файлы и прогресс исключены из Git.

В интерфейсе доступны все 248 заданий, включая пять закреплений: 247 обязательных и одно дополнительное. Поиск и фильтры охватывают полный каталог. Готовый main доступен для всех 149 программных заданий. Прогресс считает закрепления, вопросы и проекты; прочтение глав учитывается отдельно.

«Закладки» сохраняют выбранные задания, «Повторение» собирает расхождения и выполненные задания для повторной практики. Сроков прохождения нет. Дополнительная сессия с таймером доступна в последнем модуле. Подробные лекции сейчас есть только в первом модуле, остальные содержат практикумы.

## Проверка разработки

```text
npm run build
npm test
npm run test:browser
npm run test:platform-browser
```

Обычные тесты не требуют C++. Необязательный `npm run test:manual-mains` проверяет синтаксис 37 готовых main по объявлениям API в изолированном временном каталоге; он не запускает пользовательские решения и не вызывается сайтом. `npm run prepare:day01` пересоздаёт только новые условия, не перезаписывая ученические файлы.

Подробности: [учебная платформа](docs/platform.md), [лекция № 1](docs/day01-theory.md), [самостоятельная проверка](docs/self-check.md), [проверка реализации](docs/verification.md).
